ARCHIVED / NOT INSTALLED -- 2026-11-06

The user shelved capital-ship base interiors and chose to transfer the player
to capital ships in space instead. That new mechanic has not been implemented
as part of this task. Preserve this prototype; do not finish or install it
unless the user explicitly returns to this design.

Default builds disable the experiment: FREELANCER_BASE_INTERIORS is not defined.
base_interior_profiles.h and common_interior_profiles.h provide inert defaults,
the Common implementation and docked-ship refresh are excluded. Normal rooms,
characters, ship placements and ShipDealer access remain available. No new
Common.dll imports are required by this feature in default client/server builds.
The ARCHIVED marker blocks this folder's build.py, check.py and install.py.

PRESERVED WORK

- src/Common/common_interior_profiles.* and src/include/base_interior_profiles.h:
  unfinished generic [InteriorProfile] parser for a base's own INI. It selects
  by ship type or archetype, provides a room whitelist/file overrides, a start
  room and disabled services. Client/server hooks are retained but disabled.
- Room options characters=false and conditional [PlayerShipPlacement] entries,
  including shadow=false. These are also disabled by default.
- DATA_EXTRA/UNIVERSE/ROOM/RH/capital_deck.ini and
  DATA_EXTRA/SCRIPTS/BASES/capital/rh_depot_mooring.thn: initial exterior berth
  assembled from equip_depot_deck.ini's Rheinland depot shell. Furniture and
  character placements removed, original ambient scripts reused, player ship
  shown using HpMount. These assets still belong to the earlier prototype.
- tools/capital_interiors/prepare.py and preview.py: asset preparation and
  software previews using actual CMP meshes. The previews are NOT screenshots
  of the game; lighting, equipment and rotating proxies are not reproduced.
- src/include/capital_interiors.h and DATA_EXTRA/INTERFACE/capital_interiors.ini:
  obsolete first approach, preserved for reference. Production source now
  references base_interior_profiles.h instead.
- out/capital_interiors and src/obj/base_interiors contain local prototype
  artifacts. Older client/server binaries also remain in src/obj/train_yard.
  Do not install them as part of unrelated train work without rebuilding.

STATE AT SUSPENSION

It was then partially refactored to custom configuration in each base INI.
Common.dll for that refactor compiled/linked; the corresponding client/server
builds were blocked by MSBuild FileTracker access and the approval was interrupted.
The refactored system has NOT passed end-to-end tests or an in-game check.
No installation was performed, and the game's om15_01_base config and Pythonlancer
sources were not changed by this task. The original installation manifest in
out/capital_interiors/install is stale, not a deployable result.
