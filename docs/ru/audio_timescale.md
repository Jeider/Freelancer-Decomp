# Экспериментальное замедление звука

Фича выключена по умолчанию и включается на текущий запуск через отладочную консоль:

```text
AudioTimeScale 1
TimeScale 0.25
```

`ats` — сокращение `AudioTimeScale`. При масштабе 0.25 звук играет в четыре раза
медленнее и на две октавы ниже. Это изменение скорости и высоты тона; отдельные
фильтры, реверберация и плавное огибание эффекта здесь не добавлены.

Вернуть обычное время: `TimeScale 1`. Отключить только звуковую фичу:
`AudioTimeScale 0`. Настройка не сохраняется в INI. Работает только в одиночной
игре, при `0.01 <= TimeScale < 1`, в сборках с `FREELANCER_DBG_OPTIONS`.

Замедляются источники SoundManager и SoundStreamer: двигатели, форсаж, круиз,
выстрелы, взрывы, фоновые гулы, обычный и потоковый эмбиент, реплики, включая
RU-реплики `story_sounds_gen_ru.ini`. Масштаб времени умножается на собственную
высоту тона двигателя, заданную его тягой. Музыка и интерфейс исключены.

Короткие команды: `ats 1` — включить, `ats 0` — выключить, `ats` — показать состояние.
Скорость игры задаётся отдельно: например, `ts 0.25`.

Состояние находится отдельно от ABI-объектов. У затронутых источников свои часы:
проверки завершения, восстановление позиции и часы субтитров используют накопленное
время воспроизведения. Пауза его останавливает. Изменение масштаба действует на
дальнейшее воспроизведение; уже проигранная часть не пересчитывается. После выключения
индивидуальные часы сохраняются до остановки источника, чтобы не оборвать фразу.

Обычные `StartTick`, глобальный звуковой таймер, структура интерфейсов и флаги
базовых архетипов не меняются. Без включения не регистрируется callback и не
создаются дополнительные звуковые буферы. SoundManager предоставляет отдельный
экспорт `PortInstallAudioTimeScaleV1`; со старой DLL команда включения сообщает,
что расширение отсутствует. При включении уже играющий буфер без управления частотой
пересоздаётся в отдельный PCM-буфер с сохранением расчётной позиции. Ошибка создания
такого буфера отключает эффект для этого источника.

Для потоковых эффектов используется отдельный экспорт `PortSetStreamTimeScaleV1`.
Под блокировкой потока декодирования при необходимости копируется кольцевой
PCM-буфер и сохраняются его позиция, содержимое, громкость и панорама. Скорость
меняется только при переходе масштаба. Стандартный цикл обработки потоков,
базовые флаги буферов и музыка не изменены; после `ats 0` скорость восстанавливается.

Фича предназначена для редких изменений TimeScale. Она не исправляет существующие
особенности тайминга катсцен, Doppler, радиофильтров или потокового звука. При переходе
могут быть слышны щелчки; частота ограничена возможностями DirectSound. Игровая
проверка синхронизации RU-реплик остаётся за пользователем.

Сборка и автономные проверки:

```text
python tools/audio_timescale/build.py
python tools/audio_timescale/check.py
python tools/audio_timescale/install.py
python tools/audio_timescale/install.py --apply
```

Клиент перелинковывается от установленной сборки `out/base_neural/on`: меняются
только объекты `menu_sound_arch.cpp` и `dbg_console.cpp`, остальные объекты и
параметры компиляции сохраняются. Скрипт проверяет хэш клиента и неизменность
исходных объектов. При иной установленной сборке нужно выбрать её базу линковки.
Установщик копирует только `bin/freelancer.exe`, `bin/SoundManager.dll`,
`bin/SoundStreamer.dll` и их PDB.
Установленная Common.dll проверяется на наличие импортируемых клиентом символов
и не заменяется. Результаты сборки: `out/audio_timescale/build`.
Оригиналы сохраняются в `out/audio_timescale/backups/<дата>`; откат:
`python tools/audio_timescale/install.py --restore <папка резервной копии>`.
Исходные аудиофайлы не редактируются. Скрипты не запускают Freelancer или FLServer.

`check.py` проверяет отключённый путь, выбор категорий, переходы скорости,
продолжительность, паузу, смещение, отключение, отсутствие расширения, отказ буфера,
мультиплеер и переполнение счётчика. Дополнительно создаёт остановленные 2D/3D-буферы
DirectSound, проверяет копирование PCM, частоты 48000/12000/480 Гц и восстановление
48000 Гц, сочетание тяги двигателя с масштабом времени, а также сохранение позиции,
PCM, громкости и панорамы потокового эффекта. Воспроизведение звука в тесте не запускается.
