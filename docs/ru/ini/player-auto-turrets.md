# Настройка автотурелей игрока

[English](../../ini/player-auto-turrets.md) · **Русский**

Механика порта: автоматическое управление турелями игрока. Нужен `FreelancerPlayerAutoTurrets=1` при сборке Common и freelancer; сборочное значение по умолчанию — 0. См. [управление и реализацию](../player_auto_turrets.md).

**Расположение файла:** `port.ini` рядом с `freelancer.exe`, чтение через `PortConfigInt`. Включение кэшируется при первом обращении; после правки нужен перезапуск. Без настройки функция выключена. Работает только в одиночной игре.

## `[AutoTurrets]`

| Ключ | Тип | По умолчанию | Значение / допустимые значения | Источник |
|---|---|---|---|---|
| `enabled` | целочисленное boolean | `0` | `0` выключает; любое ненулевое целое включает контроллер и интерфейс SP. Приказ стрелять не выдаётся. | [Enabled](../../../src/freelancer/Client/player_auto_turrets.cpp) |
| `reserve_percent` | целое | `35` | Начальный минимальный остаток энергии оружия, ограничивается диапазоном `0..90`. Сохранённые настройки персонажа/корпуса имеют приоритет. UI переключает `0 → 20 → 35 → 50 → 0`; восстановление огня — после достижения резерва + 10 процентных пунктов. | [Reconcile / CycleReserve](../../../src/freelancer/Client/player_auto_turrets.cpp) |

Ключи имеют по одному значению. Настройки `engclass`, класса сканера, перков или бустеров контроллеру не требуются.

## Пользовательские настройки

**Расположение файла:** `GetUserDataPath()` + `\auto_turrets.ini`, обычно `Документы\My Games\Freelancer\auto_turrets.ini`. Отдельный файл от сохранений игры и `UserKeyMap.ini`. Используются Windows profile API, а не игровой BINI-парсер. Запись происходит при изменении настроек через UI.

Разделы: `v1.<имя-персонажа UTF-16 в hex>.<ID-архетипа-корпуса в hex>`. Кодируется максимум 24 кодовые единицы имени, по размеру буфера имени персонажа. Имя не становится частью файлового пути. Версия включена в название раздела.

| Ключ | Тип | По умолчанию | Значение / допустимые значения | Источник |
|---|---|---|---|---|
| `reserve_percent` | unsigned profile integer | ограниченное значение из `port.ini` | Сверху ограничивается 90. Некорректное отрицательное значение profile API читает как unsigned, поэтому оно тоже ограничится до 90. UI пишет только предусмотренные варианты. | [LoadPreferences](../../../src/freelancer/Client/player_auto_turrets.cpp) |
| `mode` | profile integer | `2` | `1`: выбранная цель; любое другое значение: свободный огонь по врагам. Только предпочтение, не разрешение стрелять. | [LoadPreferences / SetPreferredMode](../../../src/freelancer/Client/player_auto_turrets.cpp) |
| имя установленного hardpoint, например `HpTurret01` | profile integer boolean | `1` | Участие hardpoint в автоматической группе: `0` исключает, ненулевое значение включает. Применяется к подходящему оборудованию. Новое оборудование во время приказа исключается до последующего явного изменения выбора/запуска. | [SavedSelection / ToggleMember](../../../src/freelancer/Client/player_auto_turrets.cpp) |

Цель, текущий приказ, разрешение стрелять, перезарядка и энергия не сохраняются. Без доступного имени персонажа запись настроек пропускается. Ошибка записи выводит диагностику `Auto turrets: could not save preferences`; текущие настройки продолжают работать в памяти.

## Клавиатура и ресурсы

Четыре команды `USER_PLAYER_AUTO_TURRET*` регистрируются клиентом, добавляются в группу клавиш кабины и показываются в стандартных настройках клавиатуры без правки `KeyMap.ini` и `keylist.ini`. Назначения сохраняются штатным механизмом `UserKeyMap.ini`. Обязательных клавиш по умолчанию нет. Команда камеры `USER_AUTO_TURRET` не меняется.

Текст HUD использует собственные виртуальные IDS `0x7fee0000..0x7fee000b` и `0x7fee0020..0x7fee0023`; при `PortLanguage() == ru` выбирается русский, иначе английский. Подготовленная иконка имеет фиксированный путь `interface\hud\HUD_player_auto_turret.3db`; без неё используется существующая иконка выбранного объекта. Это константы реализации, а не INI-ключи.
