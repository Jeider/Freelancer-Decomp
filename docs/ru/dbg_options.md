# Окно отладочных опций беты (DBG_OPTIONS)

[English](../dbg_options.md) · **Русский**

В бете `freelancer.exe` 2002 года есть окно отладочных опций: команда кеймапа `DBG_OPTIONS`
(221), обработчик клавиш `opt_KHandler` по адресу `0x00570410`, отрисовка списка `FUN_0056ffd0`.
Оно редактирует ту же таблицу из 71 опции, что осталась в retail
([game_options.h](../../src/freelancer/Client/game_options.h)). В retail таблица и 138 её
проверок сохранились, но окно удалено, поэтому все опции всегда равны значениям по умолчанию.
Порт возвращает окно и отрисовку группы `[OUTLINES]`.

| Свойство (`src/Freelancer.Diagnostics.props`) | Define | По умолчанию в листе |
|---|---|---|
| `FreelancerDbgOptions` | `FREELANCER_DBG_OPTIONS` (клиент и `Common.dll`) | 1 |

## Окно

В retail нет команд кеймапа `DBG_*`, поэтому окно открывается по **Ctrl+Shift+O**.

| Клавиша | Действие |
|---|---|
| Вверх / вниз | выбор строки |
| Enter / пробел | включить или выключить строку (многозначная опция при включении возвращается к значению по умолчанию) |
| Влево / вправо | уменьшить / увеличить значение |
| Esc, Ctrl+Shift+O | закрыть |

Показывается вся таблица. Строки в скобках — переключатели групп, которые retail проверяет
вместе со строками под ними (`[EFFECTS]` и `PARTICLES` и т.д.). Изменение строки меняет значение,
которое читают проверки игры, поэтому остальные группы (`[OBJECTS]`, `[EFFECTS]`, `[INTERFACE]`…)
работают как в бете везде, где retail их ещё проверяет. Значения не сохраняются.

## [OUTLINES]

Рисуется поверх сцены космоса после эффектов, для объектов не дальше 7500 м от камеры
(бета `FUN_00516a10`, `DAT_005c92a0` = 56250000), когда включён `[OUTLINES]`:

| Строка | Бета | Порт |
|---|---|---|
| `PHYS WIRES` | `FUN_00516420`: для каждой физической части оболочка (CObject +0x5c) каркасом или сфера (+0x54) | все рёбра выпуклых леджей IVP-поверхности в мировых координатах (`DbgOutlineCollisionHull`); IVP-шар — сферой. Жёлтый для своего корабля, голубой для остальных |
| `PHYS SPHERES` | сферы частей | физическая сфера (`get_physical_radius_r`), пурпурная |
| `SHIELDS` | `FUN_005162c0`: физическая сфера, синяя | то же для кораблей, светлее |
| `PHANTOMS` | функтор по фантомам | фантомы, прикреплённые к объекту (CObject +0x78): коробки и части — оболочкой, сферы — сферой, зелёные |
| `HOTSPOTS` | `Client\supt\Hotspot.cpp`, собственный список хотспотов беты | не перенесено: в retail такого списка нет |

Геометрию отдаёт `Common.dll` (`src/include/common_dbg_outlines.h`). В бете и retail одна и та
же физика IVP. Обход частей по дереву инстансов движка, как в бете, заменён единой поверхностью
объекта: в ней уже есть леджи всех частей.

Собрано, не запускалось.
