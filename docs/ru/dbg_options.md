# Окно отладочных опций беты (DBG_OPTIONS)

[English](../dbg_options.md) · **Русский**

В бете `freelancer.exe` 2002 года есть окно отладочных опций: команда кеймапа `DBG_OPTIONS`
(221), обработчик клавиш `opt_KHandler` по адресу `0x00570410`, отрисовка списка `FUN_0056ffd0`.
Оно редактирует ту же таблицу из 71 опции, что осталась в retail
([game_options.h](../../src/freelancer/Client/game_options.h)). В retail таблица и 138 её
проверок сохранились, но окно удалено, поэтому все опции всегда равны значениям по умолчанию.
Порт возвращает окно и отрисовку группы `[OUTLINES]`.

| Свойство (`src/Freelancer.Diagnostics.props`) | Define | По умолчанию в листе |
|---|---|---|
| `FreelancerDbgOptions` | `FREELANCER_DBG_OPTIONS` (клиент и `Common.dll`) | 1 |

## Окно

В retail нет команд кеймапа `DBG_*`, поэтому окно открывается по **Ctrl+Shift+O**.

| Клавиша | Действие |
|---|---|
| Вверх / вниз | выбор строки |
| Enter / пробел | включить или выключить строку (многозначная опция при включении возвращается к значению по умолчанию) |
| Влево / вправо | уменьшить / увеличить значение |
| Esc, Ctrl+Shift+O | закрыть |

Показывается вся таблица. Строки в скобках — переключатели групп, которые retail проверяет
вместе со строками под ними (`[EFFECTS]` и `PARTICLES` и т.д.). Изменение строки меняет значение,
которое читают проверки игры, поэтому остальные группы (`[OBJECTS]`, `[EFFECTS]`, `[INTERFACE]`…)
работают как в бете везде, где retail их ещё проверяет. Значения не сохраняются.

## [OUTLINES]

Рисуется поверх сцены космоса после эффектов, для объектов не дальше 7500 м от камеры
(бета `FUN_00516a10`, `DAT_005c92a0` = 56250000), когда включён `[OUTLINES]`:

| Строка | Бета | Порт |
|---|---|---|
| `PHYS WIRES` | `FUN_00516420`: для каждой физической части оболочка (CObject +0x5c) каркасом или сфера (+0x54) | все рёбра выпуклых леджей IVP-поверхности в мировых координатах (`DbgOutlineCollisionHull`); IVP-шар — сферой. Жёлтый для своего корабля, голубой для остальных |
| `PHYS SPHERES` | сферы частей | физическая сфера (`get_physical_radius_r`), пурпурная |
| `SHIELDS` | `FUN_005162c0`: физическая сфера, синяя | то же для кораблей, светлее |
| `PHANTOMS` | функтор по фантомам | фантомы, прикреплённые к объекту (CObject +0x78): коробки и части — оболочкой, сферы — сферой, зелёные |
| `HOTSPOTS` | `Client\supt\Hotspot.cpp`, собственный список хотспотов беты | не перенесено: в retail такого списка нет |

Геометрию отдаёт `Common.dll` (`src/include/common_dbg_outlines.h`). В бете и retail одна и та
же физика IVP. Обход частей по дереву инстансов движка, как в бете, заменён единой поверхностью
объекта: в ней уже есть леджи всех частей.

Собрано, не запускалось.

## Консоль

Внутриигровая консоль беты (`con_KHandler` по адресу беты `0x006862a8`, отрисовка `0x00555020`,
таблица команд `0x00690fb0`; `src/freelancer/Client/dbg_console.cpp`). Клавиша **`** (под Esc;
`ё` в русской раскладке) открывает и закрывает её. Enter выполняет строку, Tab дополняет
команду, Вверх / Вниз — история, PgUp / PgDn / Home / End — прокрутка.

| Команда | Действие |
|---|---|
| `TimeScale` / `ts` [множитель] | замедлить или ускорить одиночную игру (бета `0x00550b10`; таймер кадра умножает ограниченный dt, бета `0x00427bf0`); не меньше 0.01, порт ограничивает 10 |
| `time` | секунды с начала |
| `max_fps` / `fps` [кадры] | ограничение частоты кадров (ретейл `DAT_00610a0c`) |
| `lines` [2..40] | видимые строки |
| `pos` / `p` `[x,y,z]` | позиция игрока; с координатами переносит корабль туда в этой системе |
| `clear`, `quiet` / `q`, `help` / `h`, `quit` | |

Из console.dll adoxa (`console.cpp` v1.24; серверная часть — `Server/server_port_console.cpp`,
клиент находит её через `GetProcAddress(server.dll, "PortConsoleServer")`, одиночная игра):

| Команда | Действие |
|---|---|
| `save` / `s` [имя \| 1-9] | сохранить сейчас, и в космосе (`PlayerData_SaveGame`); один символ или ничего — быстрый сейв `qsave<c>.fl` |
| `load` / `l` [имя \| 1-9] | загрузить такой сейв (`QueueLoadGameCharacter`; папку задаёт `[ModServer] account_folder`) |
| `base` <имя> | сесть на базу (nickname или часть названия; `pub::Player::ForceLand`), из космоса |
| `system` <имя> [x,y,z [rx,ry,rz] \| объект] | перейти в другую систему: в тех же координатах, в точку или к объекту (nickname или `~часть`); `SystemSwitchOutComplete` берёт это вместо врат, без автосейва |
| `jump` / `j` [вперёд,вправо,вверх \| объект] | переместиться в этой системе: на смещение, к объекту или (без аргумента) к цели |
| `launch` | взлёт с базы |
| `ghost` | переключить столкновения корабля (опция `DISABLE_COLLIDE`) |

## Камера на объект и хардпоинты

`ChaseCamera` беты (vtable беты `0x005c79e4`, обновление `0x004f1dd0`, события `0x004f2ac0`) и
её показ хардпоинтов (бета `0x0040c040` / `0x0040c160`), `dbg_chase_camera.cpp`. В ретейле нет
команд раскладки для неё, поэтому клавиши фиксированы:

| Клавиша | Действие |
|---|---|
| Ctrl+Shift+C | смотреть на цель игрока (иначе на игрока); повторно или Esc — вернуться |
| PgDn / PgUp | следующий / предыдущий корабль; с Ctrl — объект системы; при показе хардпоинтов — следующий / предыдущий хардпоинт |
| стрелки, Num+ / Num-, Home | облёт, отдалить / приблизить, сброс |
| V | вид: облёт, впереди, сзади, навстречу |
| Num* | хардпоинты: выкл., поверх всего, с проверкой глубины (оси: красная X, зелёная Y, синяя Z) |
| Backspace, I | минимальное расстояние 1; строка информации |
