# Облегчённый tlr_legal_lod5 и физические крутилки

`tools/tradelane/physical_model.py` сохраняет исходник в
`out/tradelane_physical/originals/DATA`, готовит файлы в `stage/DATA` через
Pythonlancer `DataFolder`. Состав и порядок подключений модели не меняются.

В `new_tlr_platform` удалены группы материалов 0/1 — два неподвижных обода.
Группы 2–6 — центральная модифицированная weapons platform — сохранены с прежними
вершинами, нормалями, UV и материалами. Из старого дальнего меша сохранены два
центральных компонента: LOD0 1108 треугольников вместо 3444, LOD1/2 по 132 вместо
468. Целевая проволочная модель также обновлена. Крутилки `tlr1_lod1`/`tlr2_lod1`,
их суставы, все хардпоинты и скрипты оставлены побайтно неизменными.

SUR содержит независимые секции Root и двух крутилок с `!fxd`, который в текущем
загрузчике создаёт отдельное физическое тело дочерней части. Root имеет 7 выпуклых
оболочек. Каждая крутилка состоит из четырёх раздельных деталей, нарезанных на
24 оболочки суммарно: центры проходов не заполняются общей выпуклой оболочкой.
Это приближение поверхностей, а не коллизия каждого треугольника.
В `tlr_root.sur` также заменена старая коллизия ободов на коллизию платформы.

На `Trade_Lane_Ring` включён `physical_ring_anim = true`. Common хранит этот
признак и имена `left_ring_anim`/`right_ring_anim` вне ABI солнечного архетипа,
с копированием при наследовании и удалением при освобождении определения.
Server запускает соответствующий скрипт при принятой активации первого корабля;
повторы, встречный трафик и занятый клип не перезапускают его и не создают очередь.
Отмена захода не прерывает оборот. Уничтоженные корабли удаляются из учёта.

Используется существующий `SolarAnimation`/`StartSolarAnimation`: общий серверный
таймер, сериал команд, отправка текущего времени вновь подключившимся клиентам,
очистка при удалении объекта/системы. Клиентская косметическая анимация на таких
кольцах отключена, чтобы два проигрывателя не управляли одними суставами.
В SP сервер и клиент разделяют объект Common; команда повторно его не запускает.
Другие трейдлейны сохраняют старый режим, если не включён новый признак.

Проверки:

- `python tools/tradelane/check_physical.py`: настоящие EngBase/Common/IVP,
  валидность сериализованных SUR, чтение INI без клиентского companion,
  отдельные тела, границы родителя, движение коллизий обеих сторон на протяжении
  420 кадров на сторону, пустые центры и освобождение прежнего положения.
  Выполняется для текущего CargoPod-подключения и прямого CMP; проверяется teardown.
- `python tools/tradelane/check_server_physical.py`: production-серверный обработчик
  и менеджер с подменой сетевой границы, оба направления, трафик, отмена, отсутствие
  очереди, snapshot, очистка; также проверки существующих дверей и wire codecs.
- `python tools/tradelane/check.py`: прежний клиентский режим и запрет двойного
  запуска при включённой физике.

Собираются Common/Server и клиент с поддержкой DLSS. Установщик
`tools/tradelane/install_physical.py` подготавливает, а `--apply` устанавливает
четыре DATA-файла и Common/Server/client с PDB, сохраняя backup и rollback.
Content (включая новый поиск трейдлейнов по типу) и RP9 не заменяются.
Визуальная проверка в игре, заход корабля и сетевой тест с двумя ПК остаются
необходимой проверкой поведения в реальной игровой сессии.
