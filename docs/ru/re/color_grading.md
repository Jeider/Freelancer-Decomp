# Цветокоррекция сцены

Настройки → Графика → Цветокоррекция: **Выкл.**, **Естественный**, **Тёплый**,
**Холодный**. Изменение видно сразу в интерьере/космосе; подтверждение сохраняет
выбор, отмена возвращает предыдущий. Исходное изображение — значение 0.

Естественный слегка усиливает насыщенность и контраст. Тёплый добавляет мягкий
тёплый оттенок средним тонам; холодный — холодный. Чёрная/белая точки и альфа
сохраняются. Реализация SDR, без попытки превратить изображение в HDR.

Один шейдер Direct3D 9 вызывается после сглаживания и, при включении, DLSS/resolve
суперсэмплинга, до HUD. Пресет 0 не создаёт проход и текстуру. Гамма из штатной
настройки применяется отдельно. ReShade, NGX и нейросеть для цветокоррекции не
нужны; код есть и в сборке `FreelancerDlss5=0`.

Пользовательское значение: `[ColorGrade] preset=0..3` в `PerfOptions.ini`.
Начальное значение можно задать одноимённым параметром в `bin/port.ini`;
по умолчанию 0. Цветовые параметры пресетов: `src/RP9/ColorGradeShader.h`.
Подписи RU/EN лежат в NameResources.dll и кеше Pythonlancer `text/static.py`.

Проверки: `tools/graphics_settings/check.py` (реальные методы меню и сохранение),
`check_color_grade_gpu.py` (production shader на native D3D9, сверка пикселей
с CPU, альфа/крайние тона/UI). Проверено на RTX 5080; физическая AMD не проверена.
Шейдер использует стандартный pixel shader 3.0 без расширений производителя.

Установка с проверкой хешей и резервной копией:
`tools/graphics_settings/install_color_grade.py --stage`, затем `--apply`.
