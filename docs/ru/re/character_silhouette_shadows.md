# Полный силуэт персонажа в интерьере

Персонаж не является обычным RenderInstance: тело, голова и аксессуары
собираются IDeformable::Draw. GetEngineInstance служит идентификатором корневого
объекта и не заменяет отправку всех частей деформируемого персонажа.

RoomControl теперь включает FCharacterObject в проход силуэтов. Границы берутся
из IDeformable::GetBoundSphere, объединяющего части, а геометрия отправляется
через FCharacterObject::DrawShadowGeometry. Этот метод выбирает обычные LOD,
передаёт нулевой шаг времени в SetLod и вызывает Deform::Draw; он не вызывает
DrawOpaque, поэтому не обновляет hotspot и не рисует повторно стандартную тень.

Силуэт строится до персонажей по глубине окружения. Флаг Character включает
наклонную проекцию, уже поддерживаемую room_shadow.hlsl/RP9, чтобы тело не
схлопывалось под головой при строго вертикальном свете. Шейдер сохраняет
поддержку индексированной палитры костей. Если проход не получился, стандартная
тень остаётся; при успешном проходе она подавляется для того же instance.

Проверка: `python tools/room_materials/check.py --startup-build` рисует на D3D9
отдельные части с разными индексами костей и проверяет, что площадь тени с телом
больше площади тени головы. Также проверяются обычные меши, skinning, Modelview,
прозрачность и восстановление состояния. Это синтетический GPU-тест, а не
визуальная проверка каждого игрового костюма. Персонажи с неподдерживаемой
палитрой по-прежнему ограничены правилами прохода.

Игровая запись выявила дополнительную причину: CPU-деформированные части тела
приходят с FVF 0x112 и ALPHABLENDENABLE=1. Общий запрет прозрачных материалов
исключал тело, оставляя голову и аксессуары. Для прохода персонажа смешивание
теперь заменяется проверкой альфа-покрытия (порог 0.5); для обычных объектов
запрет сохраняется. Отказ от рисования больше не сбрасывает StreamCache:
следующие группы того же меша используют уже выбранный буфер, и прежний сброс
приводил к FVF=0. GPU-тест дополнен CPU-skinned XYZ + alpha blend, отдельным
Modelview и полностью прозрачной текстурой (она не должна отбрасывать тень).
