# Поведение jflp.dll

[English](../jflp.md) · **Русский**

`jflp.dll` Джейсона Худа (кодовая часть Jason's Freelancer Patch) патчит в памяти retail
`freelancer.exe`, `common.dll`, `rendcomp.dll` и `thorn.dll` по жёстко заданным адресам, поэтому
порт загрузить её не может (см. [re/dll_inventory.md](re/dll_inventory.md)). Её поведение
переписано на C++ в тех функциях, которые она патчит, по опубликованному автором исходнику
(`jflp.c`, v1.27) со сверкой по retail-листингу; установленная DLL v1.25 содержит те же патчи,
кроме отмеченных ниже добавлений v1.26–1.27.

| Свойство (`src/Freelancer.Diagnostics.props`) | Define | По умолчанию в листе |
|---|---|---|
| `FreelancerJflp` | `FREELANCER_JFLP` (клиент и `Common.dll`) | 1 |

`src/Directory.Build.props` задаёт 0 для проектов без листа; `/p:FreelancerJflp=0` собирает
retail-поведение.

## Не перенесено

- **Остальной широкий экран jflp** (шрифты, мышь, карта, бегущая строка, прицел, обрезка списка
  контактов, пропорции роликов, `fovh` в thorn, разрешение рабочего стола). В порте свой режим
  Hor+, `FreelancerWidescreenSupport` ([hd_edition.md](hd_edition.md)), который делает то же
  (шрифт выбирается по ширине 4:3 той же высоты) и заменяет HudShift. Опции `nofovx` нет.
- **Патчи только для лога**: предупреждения FLSpew «couldnt find material 163618903», «get_zone(N)
  failed», «FATE_UNKNOWN», «Used Hostile Pick Assistance», «ArchDB::Get», «cockpit aspect» и метка
  времени в `Deform::start_aim`.
- **Круизная скорость MultiCruise** в статистике двигателя: MultiCruise.dll тоже не загружается;
  строка остаётся пустой, как у jflp без этой DLL.
- **Опции** `nostats`, `no4way`, `no8way` (из строки в `dacom.ini`): порт использует значения по
  умолчанию (статистика есть, стрейф в 8 направлениях); retail — сборка с `FreelancerJflp=0`.

## Данные

Строки IDS для статистики (945, 1695–1699, 1703, 1745, 1753, 1755, 1758–1764) есть в
`resources.dll` порта. Исправления данных JFLP (`DATA\…`, текстовые DLL) — это данные: ставьте их
в свою `DATA` и подключайте в `[Resources]`, как для оригинальной игры.

Состояние: собрано (VS 2026, v145); в игре ещё не проверено. См.
[re/deviations.md](re/deviations.md) (JFLP).
