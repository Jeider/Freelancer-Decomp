## Почему предыдущая форма не подошла

Широкие высокие плечи закрывали ступенчатое сопряжение центрального корпуса с крылом.
У верхнего крыла получалась отдельная лопатка под большой нависающей плитой.
Нижняя гондола состояла из корпуса, двух дополнительных полок и ещё одной пары крыльев:
вместо компактного узла было несколько плохо связанных ярусов. Проверка старой кинематики
не подтверждала соответствие концепту. Подгонка под неизменный ход старых ползунов слишком
рано стала определять новую форму.

Правило для продолжения BW: сначала сравнить крупные формы в выбранных видах,
затем приспосабливать механизм к принятой форме. Сохранение родной кабины обязательно.
Не заменять ступенчатый корень большой плитой и не обозначать соединение крыла
отдельными полками. Углубление должно быть частью оболочки, а не накладным рисунком.

## Повторное чтение арта

Изучены средняя строка ELITE исходного листа, SIDE и TOP рядом с ней,
дополнительный B04_VIEWS_A и принятый B04_VIEWS_B. Крупные фрагменты для просмотра
лежат в `out/ship_design/bw_family/elite/references/b04_shape_review/`.
Это увеличенные фрагменты исходных изображений; нового арта не генерировалось.
Наблюдения и контуры выбраны вручную, не автоматическим распознаванием.

| Признак на выбранном арте | Решение b04_02 |
|---|---|
| Узкий продольный верхний корпус, кабина выступает над корнями | Центральная оболочка отделена по высоте от низких боковых ступеней |
| Верхняя ступень, продольная боковая ниша, нижняя площадка и затем крыло | Последовательный переход с настоящими стенками и дном ниши |
| Широкое крыло с небольшим скосом передней кромки и несколькими уступами сзади | Новый план крыла; внешний передний угол вынесен вперёд относительно b04_01 |
| Второй длинный канал уже на крыле | Геометрический канал с двумя продольными внутренними рёбрами |
| Парные воздухозаборники перед кабиной | Две полости по сторонам узкой носовой перемычки |
| Крупная наклонная решётка кормовой щеки | Вырезана в стенке корпуса; длинные ламели находятся внутри |
| Сужающаяся книзу центральная секция с утопленными полями | Гранёный киль, глубокое боковое поле и дополнительные поля спереди/сзади |
| Компактная нижняя гондола и короткие боковые крылья | Один цельный объём с одной парой крыльев, без прежних верхней и нижней полок |
| Два прямоугольных сопла | Верхнее и нижнее; ложный третий торец исходного SIDE не переносится |

TOP использован для направления передней кромки и уступов крыла: корень около
X=2.63, наружный край X=7.05, передний наружный угол Z≈−1.98 вместо уходившего назад
в b04_01. Это ручная пространственная интерпретация рисунка, не метрическая
реконструкция ортографического чертежа. Иллюстрации имеют небольшую перспективу
и расхождения между ракурсами. Сгенерированную кабину из арта не копируем:
включение неизменной исходной кабины остаётся отдельным ограничением.

## Состояние файлов

- Статичный раскрытый LOD0, 2098 треугольников. Полноценные Blender и CMP.
- Все 126 исходных треугольников кабины/стекла сохранены вместе с UV и координатами.
- Семантические владельцы и данные исходных HP сохранены для последующей работы.
  Их окончательная посадка на новую геометрию ещё не выполнялась.
- Новый экспорт имеет свежую соль приватных 3DB/VMS; ссылки и CRC обновлены.
- Материалы CMP внешние. Временные UV ссылаются на исходную BW-библиотеку;
  оценивать форму нужно по нейтральным Blender-превью. Цветные акценты — подсказка
  для чтения секций, не утверждённая раскраска.
- Ползунки и двери не выдаются за завершённую анимацию новой формы. Источник
  и разобранная кинематика сохранены; статичная модель не содержит Animation.
- Игра, Pythonlancer, shared MAT и исходные CMP не изменены. Дальних LOD,
  разрушений, SUR и итогового HUD wire в этой версии нет.

## Проверки и воспроизводимость

Экспорт перечитан: материалы внешние, геометрия совпадает с исходными массивами
в пределах float32, данные HP не изменены, ограничения индексов соблюдены.
Проверяется неизменность SHA-256 исходного CMP и выбранных артов.
Blender использует те же массивы треугольников. Выполнены виды спереди и сзади
3/4, сбоку, сверху, сзади, снизу и трюм со скрытыми створками. Рендеры используют
отсечение обратных сторон. Для трюма проверяются лицевые попадания лучей в пол,
обе боковые и обе торцевые стенки. Сохранённый blend повторно открывается.

Эти проверки подтверждают целостность прототипа, но не художественное одобрение.
Следующий шаг — отзыв пользователя о **форме b04_02**.

```powershell
python -B -X utf8 tools/procedural_ships/bw_elite_b04_02.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/bw_elite_b04_02_blender.py
```

Точные хеши и экспортная соль — в `manifest.json`; геометрическая проверка —
в `blender_validation.json`; проверка сохранённого Blender — в `blend_readback.json`.
