# Постоянный архив промптов кораблей: RH, BW, LI и BH

По указанию пользователя от 17 ноября 2026 успешные промпты сохраняются
**даже при удалении соответствующего опыта**. Чтобы не потерять удачные
промежуточные решения, архив включает доступную историю заданий этих семейств:
первичные генерации, правки и раздельные проходы формы/материалов.
Для семейства BW здесь также сохраняются задания на целые семейные листы:
fighter, elite и vheavy_fighter в одном согласованном визуальном направлении.
Наличие исторического промпта в архиве не означает одобрения его результата.
Актуальные ограничения и выбор имеют приоритет над отклонёнными заданиями.
Для LI pirate elite с 18 ноября сохраняются исходные L01/L02, точные задания,
пять входных изображений каждого вызова и отдельные референсы исследования
арт-деко. [Исследование и первые концепты](../../../../out/ship_design/li_elite/README.md).

Первый снимок 17 ноября 2026: **21 JSON с промптами** (20 для этих двух кораблей и
один связанный файл RH elite), 37 снимков контекста и **70 изображений** после
устранения дубликатов. SHA-256 всех сохранённых файлов проверены; отдельный
`--verify` успешно выполнен без чтения исходных папок экспериментов.

## Что хранится

- `snapshots/`: неизменённые байты всех найденных JSON с промптами и правками,
  а также снимки контекста: README, выбор пользователя, аудит и манифесты серий.
  Имя снимка содержит хеш содержимого. Новые версии добавляются отдельно.
- `selected/`: удобные рецепты Q13/F14/B04/L66/BF28/BHF20 — полный точный промпт, последовательность
  референсов, копия выбранного результата, SHA-256 и основание выбора.
- [manifest.json](manifest.json): соответствие исходных путей архивным,
  хеши и размеры. Сохраняется также файл промптов RH elite, использованный
  в предыстории концептов.
- [Изображения](../../../../out/ship_design/prompt_archive/README.md): отдельные
  копии всех изображений, на которые ссылаются сохранённые промпты, включая
  промежуточные арты для последующих правок и выбранные арты.
  Одинаковое содержимое хранится один раз по SHA-256.

Тексты находятся в `docs/ru/ship_design/prompt_archive/`, изображения — в
`out/ship_design/prompt_archive/assets/`. Обе папки постоянные и не являются
папками экспериментов. Для переноса архива копировать обе вместе.
Оригинальные абсолютные пути сохранены для истории; для повторной генерации
использовать `archived_path` относительно корня репозитория. В рецептах выбранных
концептов порядок изображений уже указан. Результат новой генерации может отличаться.

Архив сохраняет изображения, явно перечисленные в JSON-промптах, включая поля
выходов новых серий, а также выбранные арты. Поэтому новые серии RH/BW/LI/BH
могут содержать все выходные листы, а не только входные референсы. Для старых
раундов, где путь финального листа не записан в JSON, наличие снимка промпта
само по себе не означает, что каждый отвергнутый PNG был продублирован.

## Сохранение следующих итераций

После успешной генерации записать точный фактически переданный промпт, параметры,
упорядоченные пути референсов и соответствие выходного файла. Обновить архив
до удаления/перезаписи опытов:

```powershell
python tools/procedural_ships/archive_ship_prompts.py
python tools/procedural_ships/archive_ship_prompts.py --verify
```

Первый вызов добавляет снимки и изображения, сохраняя прежние записи. Второй
проверяет SHA-256, тексты выбранных промптов, референсы и выбранные PNG,
читая только постоянный архив; исходные папки опытов для него не нужны.
Эта проверка подтверждает целостность сохранения, не качество новой генерации.

При уборке `round_*` **не удалять архив**, его референсы и снимки выбранных
концептов. Исходные арты и история промптов не являются лишними копиями сборок.
