# Q13 / uv_04 — светлая обшивка, красные ламели, отдельные сопла

Офлайн-прототип для следующего просмотра. Пользователем ещё не утверждён.
В игру не установлен; Freelancer/FLServer не запускались. LOD/SUR/разрушения
в этом пакете не дорабатываются.

## Открывать для просмотра

- [CMP в раскрытой полётной позе](rh_pir_freighter_review_open.cmp).
  Статическая копия: боковые узлы выдвинуты по исходной анимации, Animation
  удалён только из этой копии, чтобы просмотрщик не применял ход повторно.
- [Blender, сохранённый на кадре 211 — полёт](rh_pir_freighter_prototype.blend).
  Родная последовательность и метки на таймлайне сохранены, материалы упакованы
  для самостоятельного просмотра Blender-файла.
- [Анимированный CMP](rh_pir_freighter.cmp): родная нулевая поза сложенная,
  исходные Cons/Animation и локальные данные HP сохранены побайтно.

Оба CMP используют внешний пользовательский `rh_pir_playerships.mat` и исходный
`envmapbasic.mat`. В CMP нет Material/Texture library; отдельный MAT не создавался.
Имена приватных 3DB/VMS/wire-ресурсов получили свежую соль, различную у двух CMP.

## Что изменено по пакету скриншотов

- Передняя верхняя часть и наружные панели: спокойная светлая `panel01`,
  несколько отдельных участков вместо мелкой полосатой укладки и пёстрой panel03.
  Масштаб текстур сохраняется внутри общего участка, не сбрасывается на каждом
  треугольнике. UV-разрезы не изменяют форму.
- Верхняя сервисная площадка и два нижних выступа используют родной серый люк.
  Панели боковых плеч также получают участки люка.
- Видимая боковина горба: перенесена раскладка 49 наружных треугольников исходного
  `rh_pir_freighter` в боковой проекции. Грани новой формы разделены по исходным
  UV-границам, сохраняются круговой рисунок и светлая окантовка. Это перенос UV,
  не запекание единой картинки на весь борт.
- Наружный каркас, внутренние выступы нижней выемки и корпуса боковых узлов светлые.
  Стенки/задники выемок используют светлую `pir_r_panel01_256.tga` с коричневым
  материалом `pir_r_panel01_256D`, родной Dc = (0.470588, 0.349020, 0.094118).
- Ламели вентиляции красные (`panel02`), задняя стенка тёмно-коричневая.
  Красные поля нижнего борта убраны. Родной круговой рисунок горба сохранён.
- Днище: светлые участки, три тёмных поперечных канала, два серых сервисных люка.
- Двигатели: новый 12-гранный корпус с переходами; суженная шейка и отдельный
  выступающий обод сопла. Выпускная решётка плоская и утоплена на 1.008 единицы.
  Полость имеет стены и закрытое основание; внутренних лопастей нет. HP не двигались.

## Источники и проверки

Геометрия корпуса/механизмов — `../rig_01/mechanical_geometry.json`; предыдущий
выданный CMP `../engines_03` проверен по сохранённому SHA до сборки, ручных изменений
в нём не обнаружено. Кабина и её UV взяты без изменений из родного корабля.
Исходный CMP и общий MAT закреплены SHA-256 в [build.json](build.json).
Референсы UV — [аудит исходника](../../references/uv_native/README.md).

- 11 субмоделей, 26 135 треугольников после UV-разрезов. Это полный прототип LOD0.
- Максимум одного VMesh: 27 986 вершин / 58 920 индексов, ниже 16-битных лимитов.
- 65 фаз крышки и 49 фаз выдвижения: пересечений не обнаружено.
- Лучи из трюма попадают в лицевые стороны пола и четырёх стен; открытая крышка
  освобождает вертикальный проём. Лучи сопел подтверждают основание и боковые стены.
- Площади и границы всех 11 экспортированных частей совпадают с авторской геометрией.
  Статический раскрытый CMP после перечитывания совпадает с полётной позой анимированного.
- Внешний `metal` не использовался. Тёмно-коричневый материал проверен по реальному MAT.
- Blender сохранён и повторно открыт на кадре 211.

[Проверка поверхности/материалов](validation.json), [проверка движения](motion_check.json),
[проверка Blender](blender_check.json), [раскрытая копия](review_open_check.json).
Офлайн-проверки не заменяют последующую игровую проверку пользователем.


поправил HP, сначала перенести именно его изменения, не перезаписывать их генератором.
