# Q13 / uv_13 — длинная передняя площадка

Офлайн-прототип от 18 ноября 2026. Основание переднего карниза теперь использует
ту же комбинацию рисунков panel01, что и задний: ряд круглых деталей на фасаде
и овальный мотив на нижнем скосе. Полка удлинена по геометрии исходного
rh_freighter и сужается к передней кромке. Верх обеих полок остаётся Y=2.80.

## Модель и виды

- [Раскрытый статический CMP](rh_pir_freighter_review_open.cmp).
- [Blender в раскрытой полётной позе, кадр 211](rh_pir_freighter_prototype.blend).
- [Анимированный CMP, нулевая поза сложенная](rh_pir_freighter.cmp).
- [Новый карниз крупно](fore_corner.png), [с противоположной стороны](fore_corner_left.png).
- [Спереди](fore_front.png), [сверху](fore_top.png), [сбоку](fore_side.png).
- [Общий профиль и высота обеих полок](textured_side.png), [корабль целиком](textured_flight.png).

Полка стала на 42.2% длиннее: 3.2663 вместо 2.2970. Ширина меняется с 3.8666
у основания до 2.8431 у передней кромки; толщина 0.22. Длина и ширины взяты
из реальных треугольников 93–96 исходного rh_freighter. Толщина и положение
адаптированы к Q13. [Исходники и аудит](../../references/fore_cornice_12/README.md).

Круглый рисунок фасада не повторён зеркально и не разрезан на мелкую мозаику.
Убраны неиспользуемые светлые полосы атласа, чтобы на коротком фасаде сохранить
целые круги в масштабе заднего карниза. Светлый верх и торцы разложены отдельными
небольшими участками родной текстуры. Под полкой есть нижняя поверхность.

## Сохранённое и проверки

Кабина, двигатели, боковые узлы, кормовой карниз и поднятый пол сохранены.
Сравнение с uv_12 подтверждает все 64 HP с владельцами/ориентациями и геометрию
с UV десяти частей вне ROOT. Исходные Cons и Animation сохранены.

Всего 26 152 треугольника: на 22 больше uv_12. Максимальный VMesh содержит
30 128 вершин и 61 410 индексов; ограничения формата соблюдены.

- [65 фаз крышки и 49 фаз боковых механизмов, без найденных пересечений](motion_check.json).
- [Повторное открытие Blender](blender_check.json).

  В том же отчёте проверены поднятый пол, стенки и ранее закрытые щели.
- [Объединение двух новых объёмов с рабочей оболочкой](fore_cornice_union.json).

- [Соль и соответствие ресурсов, хеши](build.json), [файлы выдачи](delivery.json).

Крупные виды с обеих сторон, спереди, сверху и общий профиль просмотрены.
Материалы внешние: CMP не содержит Material/Texture Library. Общий MAT не
изменён. Изображения упакованы только в Blender для автономного просмотра.
Игра не запускалась, корабль не устанавливался. Это прототип для визуальной
проверки, без новых LOD, SUR и настройки разрушений.

## Воспроизведение

```powershell
python tools/procedural_ships/rh_freighter_uv13.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_rig_blender.py -- --variant uv_13 --fore-cornice-review --review-open
python tools/procedural_ships/rh_freighter_uv_package_check.py --variant uv_13
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_uv10_probe.py -- --variant uv_13
python tools/procedural_ships/rh_freighter_uv12_check.py --variant uv_13
```

Генератор проверяет хеши CMP перед перезаписью, чтобы не затереть ручные правки.
Из uv_11 восстанавливается только основа изменяемого ROOT; остальные объекты
взяты из uv_12. Предыдущие прототипы сохранены.
