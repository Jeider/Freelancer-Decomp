# Q13 / uv_06 — двигатели B3 и второй пакет UV

Офлайн-прототип для следующего визуального просмотра. Основа корпуса — Q13;
двигатели переработаны по выбранному пользователем B3. Художественное принятие
новой версии ещё впереди. В игру файлы не устанавливались, игра не запускалась.

## Модель для просмотра

- [Раскрытый статический CMP](rh_pir_freighter_review_open.cmp) — удобен для редактора.
- [Blender, сохранённый в полётной позе на кадре 211](rh_pir_freighter_prototype.blend).
- [Анимированный CMP](rh_pir_freighter.cmp) — родная сложенная нулевая поза.

Текстуры и материалы CMP остаются во внешнем пользовательском MAT. Blender
содержит упакованные изображения для удобства просмотра. Кокпит, локальные
hardpoints, их владельцы, Cons и Animation сохранены. Статическая копия имеет
отдельную соль внутренних ресурсов; она не заменяет анимированную модель.

## Двигатели: что взято из B3

[Исходный B3 sheet](../../concepts/round_03/rh_freighter_B3_sheet.png), SHA-256
`f477c947f8421a2db5dde5b26f4e78a50d9bd8632b11e9adb19c6f3d7e9de35e`.

На боковой и верхней проекциях видны вытянутый гранёный корпус, суженные
передняя и задняя части, короткий обод сопла и отдельная опора. В боковой
проекции опора поднимается от нижней части кормы к оси двигателя; сверху
пара опор расходится от кормы к двигателям. Это основа нового узла, а не
копирование прежнего двигателя rh_pir_freighter.

Новые опоры начинаются внутри кормы на Z=7.70, видимая часть проходит от
Z=8.30 до 9.35. Их центры поднимаются с Y=-1.12 до -0.28 и расходятся от
|X|=1.70 до 2.08. Под прямыми сторонами сделаны широкие грани, без мелких
декоративных крепежей. Прежние отдельные переходные блоки удалены целиком:
именно они вылезали у заднего угла бокового контура.

Корпус двигателя имеет 12 широких граней, цельный пояс красных панелей,
светлые плечи и короткое сопло. Внутри сопла есть стенки и утопленная плоская
выпускная поверхность; лопаток нет. Выпускная поверхность Z=11.15, внешний
край Z=12.158; исходные HpEngine остаются внутри канала. Позиции HP не менялись.

## Правки по десяти изображениям

[Сохранённые скриншоты и их хеши](../../references/uv_detail_06/sources.json).

| Место | Изменение |
|---|---|
| Боковины выдвижных колонн | Целые красные панели на широких стенках, светлая наружная кромка и рисунок торца сохранены. |
| Обвод верхней боковой секции, включая вентиляцию | panel03 проходит по всему внешнему периметру. Направление UV следует длине контура и не сбрасывается на диагоналях треугольников. Коричневый задник вентиляции сохранён. |
| Днище | panel03 на основных полях и наклонных переходах. Поперечные каналы остаются тёмными. Оси раскладки общие для обоих бортов. |
| Нижние люки | Две одинаковые площадки по продольной оси. Полный рисунок люка одинаковой ориентации; боковые грани коричневые. |
| Выступ у двигателя | Старые переходные блоки удалены. Опора нового двигателя входит в центральную кормовую часть. |
| Корма | Светлая верхняя поверхность с красными боковыми рядами; центральная задняя стенка темнее, две опоры образуют общую кормовую композицию. |
| Лоб | По три выровненных красных панели на каждом краю, в одной развёртке через переходы. |
| Два люка на лбу | Площадка увеличена по длине, края почти прямоугольные. Оба изображения целиком помещаются внутри; UV не обрезают рамки. |
| Baydoor | Основная раскладка сохранена. Весь профиль каждой боковой рейки развёрнут поперёк одним полотном вместо трёх параллельных повторов. Вдоль рейки сохранён разумный масштаб панелей. |

Красный цвет остаётся локальным акцентом. Полости боковых колонн используют
тёмный материал родного горба. `metal` применяется только внутри трюма/двери.

## Проверки

Перед работой оба CMP uv_05 сверены с их отчётами: ручных изменений не было.
Версия uv_05 сохранена. Источник анимации и HP — исходный игровой CMP,
закреплённый хешем в [build.json](build.json); общий MAT не изменялся.

- [Проверка геометрии новых двигателей](engine_geometry_check.json).
- [Проверки экспортированной геометрии и внешних материалов](validation.json).
- [Полная проверка движения и лучей](motion_check.json): 65 фаз крышки,
  49 фаз боковых узлов, стенки трюма, задники вентиляции и углубления сопел.
- [Повторное открытие Blender](blender_check.json).
- [Расположение UV](uv_layout.json), [проверка схлопнувшихся UV](uv_degenerate.json).

В итоговом экспорте 25 307 треугольников. Максимум одного VMesh: 28 362 вершины
и 58 779 индексов, в пределах 16-битного формата. Все 11 частей совпадают с
авторской геометрией по площади и границам, раскрытый CMP — с полётной позой.
Пересечений в проверенных фазах нет.

Отдельно проверена площадь UV: на изменённых узлах схлопнувшихся поверхностей
нет. У uv_05 боковины/торцы baydoor содержали 345 таких треугольников площадью
5.477; в uv_06 эта проблема устранена. Неизменными остались шесть треугольников
родного стекла с постоянными UV и две крошечные грани исходной проекции горба
общей площадью 0.00887. Они не относятся к новой раскладке рейки.

Не считать техническое прохождение проверок подтверждением художественного
соответствия арту. Это LOD0-прототип; SUR, дальние LOD и разрушение пока не делаются.

## Воспроизведение

```powershell
python tools/procedural_ships/rh_freighter_uv_b3.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_rig_blender.py -- --variant uv_06 --b3-review --review-open
python tools/procedural_ships/rh_freighter_uv_package_check.py --variant uv_06
```

Перед новым проходом сверять хеши выданных CMP и сохранять ручные изменения
пользователя. Генератор не устанавливает файлы в DATA.
