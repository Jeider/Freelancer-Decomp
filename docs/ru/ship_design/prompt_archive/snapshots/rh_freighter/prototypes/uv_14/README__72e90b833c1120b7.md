# Q13 / uv_14 — цельная текстура верхней полки

18 ноября 2026. Убрано чрезмерное замощение верхней передней площадки.

этой полки из rh_pir_freighter, треугольники 93/94. Используется та же внешняя
текстура pir_r_panel01_256. Фасад с круглыми деталями и нижний переход сохраняются.
