# Q13/04 — небольшой выступ на шее

Обе продольные «ноздри» удалены из геометрии. Вместо них один широкий,
короткий и низкий выступ ближе к основанию корпуса. Он продолжает наклон
шейной поверхности, имеет плоскую верхнюю грань и наклонные боковые переходы.

- [Модель Blender](rh_freighter_q13_form.blend).
- [Шея крупным планом](form_front.png).
- [Общий ракурс](form_perspective.png).

Размер основания: 3.20 поперёк × 1.06 вдоль корпуса. Подъём над прежней плоскостью:
0.18 по вертикали. Выступ является частью замкнутой оболочки корпуса; старых
вырезов под ним нет. Вторая симметричная накладка не добавлялась.

Остальная форма — из Q13/03: рельеф бортов, ступени днища, плоские сопла и
исходный кокпит. 7154 треугольника, 46 объектов до объединения копланарных граней.
[Проверка правок](revision_check.json), [проверка Blender](blender_check.json).

Генерация: `python tools/procedural_ships/rh_freighter_q13_refine.py --raised-neck`.
Blender через `tools/blender_workspace.py`, скрипт `rh_freighter_q13_form_blender.py`
с аргументами `--variant q13_04`.

Это статический прототип без текстур и установки. [Предыдущая версия](../q13_03/README.md)
сохранена для сравнения.
