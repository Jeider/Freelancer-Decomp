## Изменения

В нижней выемке каждого борта три выступающие секции с разными контурами и
высотами: передний угловой возврат, средняя ступень и большая кормовая секция
с вырезом на стыке. Их основания входят в задник выемки, а передние плоскости
остаются ниже кромки на 0.09–0.21 единицы модели. Сама выемка углублена;
наружный контур и кромка сохранены. Проверено размещение в её периметре.

Днище перестроено: три поперечных углублённых канала с наклонными переходами
делят его на объёмные секции. На двух средних полях есть невысокие продольные
рёбра с наклонными окончаниями; они не перекрывают поперечные каналы. Нижняя
граница корабля не увеличена. Дно замкнуто, каналы не являются сквозными дырами.

Из обоих сопел удалены внутренние лопатки и глубокая камера. Внутри прежнего
внешнего обода теперь плоский торец. Внешняя форма двигателей сохранена.

На наклонной площадке за кокпитом два продольных углубления с наклонными стенками.
Это настоящие карманы в поверхности, с задником; не приклеенные сверху пластины.

не пересекали корабль при осмотре. Коллекция Review studio сохранена для рендеров.
