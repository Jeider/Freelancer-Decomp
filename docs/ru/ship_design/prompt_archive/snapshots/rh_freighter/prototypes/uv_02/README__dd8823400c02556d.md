## Раскладка

Вместо масштабирования небольшого фрагмента на весь борт — локальные карты
с ограниченным физическим размером. Крупные исходные треугольники разрезаны
по границам этих UV-карт; новые точки интерполированы на прежних поверхностях.
Площадь и габариты каждой детали сверены до/после. Силуэт, вырезы и механика
остались от rig_01.

- panel03 используется на плечах, бортовых полях, круглых щёках, днище и
  части внутренних панелей: мелкая составная обшивка вместо огромных пятен.
- panel01 задаёт светлые кромки и секции наружной обшивки. Крышка повторяет
  конкретную область исходной baydoor: U=129/255…1, V=220/255…1. Центральная
  часть крышки разделена на 12 коротких секций по дуге.
- panel02 — небольшие красные вставки, торцы цилиндров и более тёмные ниши.
- Семейство metal остаётся внутри трюма и на изнанке крышки.
- На дугах, двигателях и цилиндрах общая развёртка идёт вдоль физического
  пояса. Булевы фрагменты не начинают свою текстуру заново на каждом треугольнике.

В большинстве новых карт размеры не превышают примерно 1.5–2.6 единицы модели;
исключение — родная широкая, но короткая по дуге полоса крышки. Сопла и
исходный кокпит сохраняют свои назначения. Общий MAT не изменён; в CMP нет
встроенных Material/Texture library. Требуются те же внешние библиотеки:

```ini
material_library = ships\rheinland\rh_pir_playerships.mat
material_library = fx\envmapbasic.mat
```

## Проверка

20388 треугольников после разрезания UV, без новых выступов/фасок/изменения формы.
Наибольшая VMesh: 22112 вершин и 34239 индексов — в проверенных 16-битных пределах.
Все родные HP и данные Cons/Animation сохранены побайтно. 65 промежуточных
поз крышки и 49 поз боковых узлов проходят проверку пересечений. Трюм закрыт
полом, бортами и торцами; Blender сохранён и повторно открыт.

Плотность проверяется по площади реальных экспортированных треугольников,
а не только по прямоугольникам UV. [Численное сравнение](uv_check.json)
включает родной корабль, rig_01 и этот вариант. Это помогает находить растяжения,
но не заменяет оценку рисунка на ракурсах. Медианная плотность нового прототипа
около 0.199 UV/единицу; у оригинала — см. native в отчёте.

Материалы и соль экспорта: [build.json](build.json). Раскладка по объектам:
[uv_layout.json](uv_layout.json). Проверки движения и Blender:
[motion_check.json](motion_check.json), [blender_check.json](blender_check.json).

Это по-прежнему один ближний LOD. Финальные LOD, SUR, HUD-wire и разрушения
не делались. Запуска игры и изменений игрового DATA/shiparch не было.
В Blender кадр 1 — сложенная поза, 211 — полёт, 485 — открытый трюм;
остальная шкала описана в [механическом прототипе](../rig_01/README.md).

## Повторение

```powershell
python tools/procedural_ships/rh_freighter_uv_audit.py
python tools/procedural_ships/rh_freighter_uv_refine.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_rig_blender.py -- --variant uv_02
python tools/procedural_ships/rh_freighter_uv_report.py
```

Скрипт не переписывает rig_01. Если его CMP был изменён вручную, сборка
останавливается по несовпадению хеша: сначала нужно сохранить правки HP,
а не восстанавливать старые координаты поверх них.
