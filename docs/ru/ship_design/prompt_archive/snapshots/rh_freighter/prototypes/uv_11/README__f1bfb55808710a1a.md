# Q13 / uv_11 — одиночный кормовой карниз

Офлайн-прототип от 18 ноября 2026. На верхней корме сделана горизонтальная полка
с наклонным возвратом и центральной рамкой до красного поперечного пояса.
Форма и сочетание текстур разобраны по реальному исходному rh_freighter;
использован один мотив вместо двух зеркальных половин.

## Конструкция и UV

Ширина центральной полки — 2.74. Верх горизонтальный на Y=2.80, выступает до
Z=9.02. Фасад на Z=8.86; его нижняя часть возвращается наклонной плоскостью к
Z=8.51. Рамка ниже заканчивается на Y=0, точно у красного пояса. У рамки есть
стенки и утопленный закрытый задник. Корпус и карниз объединены; погребённые
пересечения удалены, замкнутость проверена.

Ряд круглых деталей и большой овальный рисунок нижнего скоса взяты из двух
разных участков native panel01. В оригинале каждая половина имеет свой мотив;
здесь одна исходная половина отображается на всю новую центральную ширину.
Не добавлены повтор, зеркальный дубль или центральный шов. Верх и боковины —
светлая обшивка, рамка использует узкие светлые участки того же атласа.
Стенки углубления — штатный тёмно-коричневый материал panel01D.

[Разбор исходника, точные пути, хеши и UV](../../references/stern_cornice_11/README.md).
[Профиль и ссылка на исходные треугольники](cornice_geometry.json).

Положение двигателей и их открытых креплений сохранено. Пол трюма по-прежнему
на Y=0.355: от кромки Y=3.81 глубина составляет 3.455, вдвое меньше прежней.
Нативная крышка проходит под настилом; торцевые зазоры не изменены. Принятая
развёртка боковинок, кабина, baydoor и боковые механизмы сохранены.

## Воспроизведение

```powershell
python tools/procedural_ships/rh_freighter_uv11.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_rig_blender.py -- --variant uv_11 --cornice-review --review-open
python tools/procedural_ships/rh_freighter_uv_package_check.py --variant uv_11
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_uv10_probe.py -- --variant uv_11
python tools/procedural_ships/rh_freighter_uv11_check.py
```

Генератор проверяет хеши предыдущих и текущих CMP перед перезаписью, чтобы не
затереть ручные правки. Boolean выполняется через штатную Blender-обёртку.
Перед объединением согласованы слоты материалов и индексы полигонов; после него
проверено сохранение всех восьми смысловых групп карниза. Предыдущая uv_10 сохранена.
