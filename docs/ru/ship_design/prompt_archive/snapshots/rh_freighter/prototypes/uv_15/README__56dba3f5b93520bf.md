# Q13 / uv_15 — симметричные карнизы

18 ноября 2026. Убрано мелкое повторение панелей на светлом корпусе под передним
выступом. Обшивка получила один крупный участок panel01. Задний карниз построен
зеркальным повторением переднего основания и площадки, без масштабирования.
Корма получила такой же заметный вылет; новый узел немного перекрывает красную
окантовку, как разрешил пользователь.

## Воспроизведение

```powershell
python tools/procedural_ships/rh_freighter_uv15.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_rig_blender.py -- --variant uv_15 --symmetric-cornices-review --review-open
python tools/procedural_ships/rh_freighter_uv_package_check.py --variant uv_15
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_cornice_probe.py
```

В этой сборке для совпадающих плоскостей старого и нового карниза использован
Blender Manifold Boolean. Проверяется не только замкнутость, но и сохранение
габаритов входного корпуса после каждого объединения: пустой результат может
не иметь неманифолдных рёбер, поэтому одного такого счётчика недостаточно.
