# RH pirate freighter — Q13 / engines 03

Двигатели переработаны по запросу пользователя. Основной референс — нижний
правый вид TOP / FLIGHT выбранного [Q13](../../concepts/round_10/rh_freighter_Q13_sheet.png).
Форма двигателей предыдущего прототипа была слишком округлой; новый вариант
использует широкие прямые стенки и выраженные угловатые переходы.

Внешний корпус двигателя построен как прямоугольный блок со срезанными углами:
четыре широкие плоскости и четыре угловые грани. Верх и борта центральной
секции прямые; к креплению и корме идут отдельные крупные наклонные плоскости.
Равномерного круглого сечения больше нет.

Сопло находится на Z=11.15, задняя кромка корпуса — Z=12.158. Углубление
составляет 1.008 единицы модели. Сделаны настоящие тёмные стенки канала и
закрытая плоская поверхность выхлопа. Внутренних спиц нет. Родные HpEngine01/02
сохранены, их Z около 11.4003 — теперь они находятся внутри открытого канала
между плоскостью сопла и кромкой, не за заглушающей поверхностью.

Новые двигатели используют небольшие участки panel01/02/03: светлые грани,
красные панели на широких плоскостях и тёмные внутренние стенки. Материал
engine_grill01 расположен на углублённой поверхности выхлопа. Семейство metal
снаружи не применяется. Общий MAT не изменён; материалы и текстуры в CMP
не встроены. Нужны прежние rh_pir_playerships.mat и fx/envmapbasic.mat.

## Что проверено

- Каждый двигатель до разделения UV: 108 треугольников, одна замкнутая оболочка,
  0 открытых/неманифолдных рёбер, согласованное направление граней.
- После UV: 424 треугольника на двигатель; весь корабль — 19620.
- Девять остальных семантических деталей совпадают с uv_02 по всем вершинам,
  нормалям, UV и материалам. Проверяется декодированный CMP после экспорта.
- Родные 64 HP, Cons и Animation сохранены; внутренние ресурсы имеют свежую соль.
- 65 фаз baydoor и 49 фаз выдвижных узлов: пересечений с новой геометрией нет.
- По пять лучей сзади для каждого двигателя доходят до лицевой поверхности
  углублённого сопла; четыре боковых луча из канала проверяют наличие его стенок.
- Blender сохранён и повторно открыт. Нулевая поза остаётся сложенной.

Отчёты: [engine_check.json](engine_check.json), [build.json](build.json),
[motion_check.json](motion_check.json), [blender_check.json](blender_check.json).

Это отдельный прототип для проверки формы. Дальние LOD, SUR, окончательный
HUD-wire и разрушения остаются следующим этапом. В игру не установлен,
shiparch не изменён, Freelancer не запускался.

## Воспроизведение

```powershell
python tools/procedural_ships/rh_freighter_engines.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_rig_blender.py -- --variant engines_03 --engine-review
python tools/procedural_ships/rh_freighter_engines_report.py
```

Скрипт проверяет хеш исходного uv_02 перед сборкой. Если пользователь изменил
его CMP вручную, сначала нужно перенести его правки HP, а не восстанавливать
старую расстановку. Прототип uv_02 остаётся отдельным файлом.
