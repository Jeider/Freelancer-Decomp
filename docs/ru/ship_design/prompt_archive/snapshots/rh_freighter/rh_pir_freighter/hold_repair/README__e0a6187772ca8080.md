# RH pirate freighter — исправление окружения трюма

Готовая офлайн-ревизия. Игровые файлы и исходники Pythonlancer не перезаписывались;
установка остаётся у пользователя согласно последним присланным инструкциям AGENTS.md.

в нём нет игровой анимации.

## Исправлено

Предыдущее сужение трюма затронуло окружающий корпус: появились растянутые
переходы, складки в UV и незакрытые сверху карманы механизмов. Исходная форма
палуб и карнизов восстановлена. Узкий трюм теперь имеет отдельные ровные стенки,
торцы и пол; над боковыми камерами механизмов сделаны цельные светлые площадки.
Пол сохранён на Y=0,355, внутренняя ширина — 2,20, наружная — 2,50.
Внутренние торцы Z=-2,51/4,39 оставляют проход вращающейся крыше.
После замечаний пользователя оба торцевых зазора закрыты светлыми панелями.
Их внутренний профиль огибает полный ход крыши: радиус центральной оболочки
4,51, направляющих 4,65, добавленный рабочий зазор 0,028. Передний и задний
торцы проверены отдельно, включая участки возле направляющих.

Моргание на внутренней кромке вызвали совпадающие грани отдельных замкнутых
деталей: стенка трюма, её верхняя грань и боковая площадка. Они объединены
в цельный объём вместе с торцами и окружающим корпусом. На 12 контрольных
лучах к кромке теперь ровно одна видимая поверхность. У каждого торца ещё
по шесть лучей подтверждают наличие панели; UV этих участков не вырождены.

Светлая внешняя обшивка использует родной `panel01`; материал `metal03D`
оставлен только внутри трюма. Дальние корпуса перестроены отдельно, без
деформации внешних площадок вслед за шириной пола. LOD: **26484 / 1544 / 500**.
На дальнем корпусе 42 треугольника, замкнутость и обход граней проверены.

Источник — текущий игровой `rh_pir_freighter.cmp`, закреплённый как
[user_source.cmp](user_source.cmp), SHA256:
`ca09e8df851e928c6492284df58d61dea5892ad411dc827f92dc81a1406c928e`.

По сравнению с предыдущим экспортом изменены `HpDocklight01/02` и
`HpRunningLight03/04/05/06/07`. Приняты все 68 текущих HP, а не только эти семь.
Их локальные координаты, ориентации, владельцы и остальные поля сохранены
побайтно. Никакого автоматического выравнивания огней в этой ревизии нет.

## Проверки

- Повторно прочитанный CMP: геометрия, все внешние материалы, индексы DirectX,
  сохранность HP, анимаций/Cons и всех линий принятого раздельного HUD-wire.
- Ближний LOD: 65 положений крыши, 49 положений ползунов, без пересечений.
- Пол по сетке из 12 лучей, четыре внутренние стенки и торцы видны лицевой
  стороной; при открытой крыше центральная ось свободна.
- Глубина разломов сохранена: примерно 1,88–1,99 в основных проверенных точках;
  у верхнего плеча горба остаётся прежняя более близкая опора.
- Сохранённый Blender открыт повторно; коллекция повреждений скрыта и в
  viewport, и при рендере. Для просмотра повреждения скрыть целую боковую
  панель и её дочерние `btn`, затем включить нужный повреждённый объект.
- Превью созданы офлайн из экспортированного CMP с отсечением обратных граней.
  Полная проверка движения относится к LOD0; дальние LOD являются упрощёнными
  визуальными оболочками. Игра не запускалась.

## Воспроизведение

Из корня репозитория, все операции локальные:

```powershell
python tools/procedural_ships/rh_freighter_hold_repair.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_hold_repair_blender.py
python tools/procedural_ships/rh_freighter_hold_repair.py --export
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_hold_repair_check.py
python tools/procedural_ships/rh_freighter_hold_repair_preview.py
python tools/procedural_ships/rh_freighter_hold_repair.py --verify
```

Подготовка намеренно остановится, если текущий игровой CMP отличается от
закреплённого пользовательского исходника: новые ручные правки нельзя потерять.
