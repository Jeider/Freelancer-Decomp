## Изменения и проверки

Пол трюма сужен с полуширины 2,405 до 1,105; внутренние стенки расположены
примерно на ±1,098, наружная стенка — на ±1,25. Большие `btn` в полностью
сложенном положении доходят примерно до ±1,51. Высота пола сохранена: Y=0,355.
Сужены и торцы; для поворота крыши вырезан замкнутый канал её полного хода.

Внутреннее оборудование повреждённых панелей перенесено с X≈3,08–3,78
на X≈1,40–1,89 (зеркально на другом борту). Удлинённые отогнутые полосы соединены
с этой конструкцией; первые верхние отрывы остаются закреплены в сохранившейся обшивке.
В основных точках разрыва проверенная видимая глубина около 1,8–1,95 единицы модели.
Верхнее плечо горба сохранено и местами выступает ближе; это не стенка трюма.

Все 10 световых HP перенесены на реальные поверхности неподвижного корпуса.
Кормовые огни подняты над двигателями; пары выровнены симметрично.
Проверены зазор до поверхности и свободный луч наружу через целую сборку.
Остальные 58 HP, их владельцы и все ориентации сохранены побайтно.

LOD: **26961 / 1776 / 494** треугольника. Ближний добавил 852 треугольника
для закрытых стенок и канала; новый внутренний блок упрощён перед экспортом.
Дальние оболочки сужены с прежним числом треугольников и прежним атласом.
Сохранены все 398 линий принятого HUD-wire и принадлежность линий деталям.

Проверки ближнего экспортированного CMP: 65 положений крыши и 49 положений
ползунов, без пересечений; лучи к полу, стенкам и торцам трюма с проверкой
лицевой стороны; свободная вертикальная ось при открытой крыше; глубина повреждений
в сохранившейся сборке. Дальние LOD — прежние упрощённые оболочки, точность
внутреннего механизма проверялась на ближнем LOD. Части повреждений замкнуты,
связь корней отогнутых полос проверена пересечением с несущей геометрией.
Контроль 16-битных индексов, внешних материалов, неизменности Cons/Animation
и свежих приватных имён проходит. Игра не запускалась.

## Воспроизведение

Запускать из корня репозитория. Скрипты пишут только в эту офлайн-папку:

```powershell
python tools/procedural_ships/rh_freighter_hold.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_hold_blender.py
python tools/procedural_ships/rh_freighter_hold.py --export
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_freighter_hold_blender.py -- --check
python tools/procedural_ships/rh_freighter_hold_preview.py
python tools/procedural_ships/rh_freighter_hold_preview.py --lights
```

Перед новой правкой сравнить пользовательский CMP с последним экспортом.
Не пересобирать эту ревизию из старого `assets/rh_pir_freighter.cmp`:
он предшествует принятым дальним LOD и верхним разделителям вайрфрейма.
