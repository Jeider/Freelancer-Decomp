# RH pirate freighter: LOD 26109 / 1776 / 494 и деление крыши в HUD

18 ноября 2026. Пользователь перенёс вариант 1776 во второй LOD,
а третьему задал предел около 500 треугольников. Новый третий содержит 494.
Установленная модель и исходные assets Pythonlancer не изменялись.

| Уровень | Было треугольников | Стало |
| --- | ---: | ---: |
| Level0 | 26109 | 26109 |
| Level1 — второй | 8934 | 1776 |
| Level2 — третий | 6906 | 494 |

Последний LOD — простые объёмы с проекционными фотографиями, плоским дном,
упрощёнными кабиной, горбом и боковыми узлами. Второй LOD сохраняет предыдущую
сетку на 1776 без повторного упрощения. Ближняя геометрия не меняется.
Это сокращение геометрии, а не измеренный прирост FPS.

CMP использует прежние внешние материалы, включая
`rh_pir_freighter_projection_lod` / `rh_pir_freighter_projection_lod.tga`.
Атлас не перезапекался, отдельный MAT повторно не выпускается.
SUR и повреждённые 3DB/SUR используются из существующего комплекта без изменений.

Level0 совпадает с предыдущим CMP по всем вершинам, нормалям и UV.
Сохранены 68 HP, байты Cons/Animation и владельцы деталей.
Все прежние wire-линии сохранены. В Root добавлены четыре поперечных профиля
крыши и две границы передней/задней площадок — всего 30 отрезков.
Панели и двигатели используют прежние собственные wire-ресурсы для повреждений.
HUD остаётся статическим и раскрытым, независимо от треугольной сетки Level2.
Приватные имена и ссылки пересолены; семантические Object/HP/material имена стабильны.
Проверены повторное чтение CMP, индексы, конечность координат, материалы,
обратное преобразование нового LOD в мировую раскрытую позу и пределы 16 бит.
Превью сняты из декодированного CMP с отсечением обратных граней.

## Что изменилось в сетке

Крышка трюма: 1690 → 102 треугольника, с прежними двумя материалами и UV.
Боковые панели: 432/423 → 36/36; мелкие вырезы и вентиляция перенесены в
существующие фотографии, при этом вогнутый внешний контур сохранён.
Горб стал простой оболочкой без геометрии внутренних колец.
Двигатели сохраняют отдельно выраженные узкие опоры; движущиеся боковые
элементы принадлежат прежним дочерним узлам.

Повторение: `rh_freighter_far_lod_blender.py` через `tools/blender_workspace.py`,
затем обычным Python `rh_freighter_min_lod.py`, `rh_freighter_far_lod.py`
и его `--preview`. `far_world.json` хранит сетку 1776 для второго LOD,
`minimum_world.json` — сетку 494 для третьего.
Полный офлайн-сборщик `rh_freighter_final_build.py` также применяет этот порядок
LOD и добавляет новые верхние HUD-линии. Исходные assets Pythonlancer и активные
DATA/shiparch этим обновлением не менялись.
