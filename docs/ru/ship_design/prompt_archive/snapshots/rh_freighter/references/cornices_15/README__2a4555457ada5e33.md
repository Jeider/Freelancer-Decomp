# Правки корпуса и симметрия карнизов

18 ноября 2026. [Первый снимок](1_lb9eE8.png) показывает частое замощение UV на
светлой обшивке под передним выступом. Требование: уменьшить его, как уже сделано
на верхней площадке. [Второй снимок](2_ZUHA10.png) — задний узел, которому нужен
такой же мощный выступ; разрешено немного зайти на красную окантовку.

Последующее явное уточнение: «симметрия важна. карнизы должны быть симметричны».
Заднее основание и полка копируются отражением принятой передней формы.
Размеры не подгоняются независимо. Нижняя кормовая ниша остаётся частью корпуса.
