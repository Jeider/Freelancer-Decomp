# Передний карниз RH freighter

18 ноября 2026. Продолжение работы с [кормовым карнизом](../stern_cornice_11/README.md).
Пользователь просит убрать два люка на лбу Q13, заменить их горизонтальным
карнизом по исходному горбуну и опустить нижнюю часть до ближайшего корпуса.
Последнее уточнение: **верх передней и задней полок на одной высоте**. Раннюю
красную отметку возле верхнего борта не использовать как окончательную высоту.

## Наблюдения

Верхняя выступающая полка оригинала горизонтальна на Y=3.776, её передний край
достигает Z=−8.736, задний — Z=−5.469; к носу она сужается. Треугольники 93/94
используют крупную светлую панель panel01. Тонкая кромка 95/96 использует узкую
светлую полосу U≈0.0904…0.135, V≈0.4159…0.6541. Лобовая плоскость 366/367 и
471/472 использует светлый участок с нарисованными крепежами у краёв. Под ней
идёт дальнейший переход к шее, а не открытая дыра в корпусе.

В прототипе uv_12 эти особенности адаптированы к короткому скату Q13: полка
ниже оригинальной, на Y=2.80 согласно заднему карнизу. Нижний переход обрывается
только при соединении с существующей обшивкой. Длинная исходная шея и кокпит
не переносятся и не масштабируются. На фасаде один светлый рисунок; его UV
удерживаются внутри границы атласа, без исходного выхода U за единицу.

Последующая правка пользователя, uv_13: «затекстурь его так же, как задний.
именной саму основу. и сделай длинную площадку как в rh_freighter».
Фасад теперь использует кормовой ряд круглых деталей panel01, нижний скос —
овальный мотив той же текстуры. Площадка получает длину и сужение оригинальных
треугольников 93–96, с адаптированной толщиной 0.22 и прежней высотой Y=2.80.
Длина 3.2663 вместо 2.2970; исходные длина и ширины сверены с экспортированным
CMP. Светлая раскладка uv_12 остаётся только историей, а не текущим требованием.

Уточнение uv_14: верхняя площадка была слишком часто замощена. Её верх теперь
получает цельные UV исходных треугольников 93/94, без повторения мелких панелей.
Основание и размеры uv_13 сохраняются. Старый игровой путь модели уже занят
прототипом; для дальнейшей работы закреплён [оригинал с проверенным хешем](../native_source/README.md).
