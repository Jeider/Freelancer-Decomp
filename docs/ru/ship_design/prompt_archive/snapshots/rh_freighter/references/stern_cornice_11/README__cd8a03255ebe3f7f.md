# Карниз исходного RH freighter — разбор для uv_11

18 ноября 2026. Пользователь просит один горизонтальный выступ на верхней корме
Q13 и центральный карниз до красного поперечного пояса. Геометрический образец —
исходный горбун; повторить сочетание текстур, но использовать один мотив вместо
двух зеркальных половин оригинала.

## Что проверено в меше

В native-координатах кормовая плоскость оригинала имеет ширину X=−3.15…3.15,
высоту Y=2.587…4.118 и Z=7.298. Наклонный возврат опускается к Y=1.922,
Z=6.286. Верхняя полка действительно горизонтальна: Y=4.214, выступ до Z=8.102.

Реальные UV взяты из треугольников ROOT, записанных в [native_stern.json](native_stern.json):

- 330/331: одна половина фасада, U=0.5059…1, V=0…0.2627; ряд круглых деталей
  и светлая полоса над ним. Половины оригинала зеркально соединяются по X=0.
- 328/441: нижний наклон, U=0.5137…0, V=0…0.2627; один большой овальный мотив.
- 478…485: нижняя рамка, светлые узкие участки той же panel01.

В прототипе UV одной половины фасада занимают всю ширину нового карниза,
без отражённой копии и центральной перегородки. Используется пиратская версия
`pir_r_panel01_256` из внешнего MAT. Извлечённая выборка исходника по Z не содержит
всего корпуса; её пустоты в отладочном изображении не переносятся в новый меш.
