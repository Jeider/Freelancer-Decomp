# Исходная поворотная крышка RH freighter

[Три фазы на исходной геометрии](native_baydoor_motion.jpg), [аудит](audit.json).
`Baydoor_lod1` вращается на 120° вокруг поперечной X за 2.1333 с.
Боковые щёки кругового горба неподвижны; между ними крышка уходит назад и вниз.
Угловатость нового корпуса не должна уничтожать этот круговой профиль.

Источник и SHA-256, привязка Root, ось, ключи, границы движущейся части и
направление воспроизведения сохранены в аудите. Рендер офлайн, без запуска игры.

Воспроизведение: `python -B tools/procedural_ships/rh_freighter_baydoor_refs.py`.
Материалы и геометрия исходного CMP не меняются. В локальной копии сцены имена
частей переводятся в нижний регистр перед сопоставлением с Cmpnd; без этого
регистрозависимый поиск старого общего sampler не применял движение.
Этот скрипт не изменяет общий sampler или результаты других задач.
