# Родные материалы и UV rh_pir_freighter

Снято чтением исходного CMP и rh_pir_playerships.mat; исходные файлы не изменены.
Точные пути и хеши: ../../prototypes/rig_01/build.json.

- [Все атласы rh_pir](rh_pir_atlases.jpg), включая damage только для справки;
  damage-атлас на неповреждённый прототип не применяется.
- [panel03](pir_r_panel03_256.png) — мелкие взаимосвязанные поля обшивки.
- [Родная UV крышки](baydoor_uv_pir_r_panel01_2562side.png).
- [Материалы и параметры](materials.json), [использование и плотность по деталям](native_usage.json).
- native_geometry.json — исходные треугольники в полётной позе с материалами/UV.

Крышка: 20 треугольников, повторяемая полоса panel01, U=129/255…1,
V=220/255…1. Плотность 0.1153857 UV/единицу. Таким образом, исходная крышка
читалась как набор коротких секций, а не одно большое изображение.

panel03 у исходника есть на Root и обоих неподвижных боковых узлах,
с плотностью примерно 0.21–0.23 UV/единицу. Она важна для мелкого масштаба
обшивки и должна использоваться в новом корпусе вместе с panel01 и panel02.

Генератор: tools/procedural_ships/rh_freighter_uv_audit.py.
