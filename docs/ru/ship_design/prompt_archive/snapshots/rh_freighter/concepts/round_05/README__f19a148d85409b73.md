## Общие ограничения и механика

- Кокпит остаётся исходным модулем RH freighter. Новую кабину для выбранного
  варианта не проектируем; в будущей геометрии переиспользуем оригинальную
  оболочку, остекление, материалы, UV и cockpit-ресурсы.
- Размер и пропорции ориентированы на установленный исходный корабль:
  W 9.4647 / H 11.4625 / L 23.7217. Высокий арочный горб обязателен.
- Крыльев нет; массивные выступы корпуса несут по три боковых цилиндра:
  большой центральный и два малых. Все листы показывают полёт с выдвинутыми
  цилиндрами. При возвращении на базу они должны уходить в свои корпуса.
- Исходный механизм использует четыре Pris-канала: большой цилиндр и малая
  пара отдельно на каждом борту. Новые неподвижные рамы и бронеплиты должны
  оставлять ход этого механизма свободным.
- Основных двигателей два, по бокам кормы на одной высоте. У J18 исправлена
  первоначальная ошибка профиля с разнесёнными по высоте силуэтами.
- Грузовые захваты, упоры и буксирные крепления — предложения формы; их новую
  кинематику пока не разрабатывали. Оружие остаётся отдельным игровым оборудованием.
- Семейство материалов `metal`/`metal03` остаётся зарезервированным для внутренности
  грузового отсека и не должно использоваться на новой внешней геометрии.

Различия построены вокруг крупных объёмов: оболочек и нижнего пояса брони,
грузовых механизмов, диагональных рам, стяжек, восстановленных донорских секций.
Подробности каждой конструкции сохранены в её полном промпте.
