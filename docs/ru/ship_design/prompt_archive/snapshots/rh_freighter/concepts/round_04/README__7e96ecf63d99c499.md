# RH freighter: конструктивная версия джанкеров, A4–E4

17 ноября 2026. Пользователь попросил выразить пиратский характер через
конструкцию корабля: джанкеры, сборщики лома, злодеи. Предыдущая версия слишком
напоминала обычный грузовик с другой окраской. Этот комплект развивает пять
разных переделок корпуса вокруг исходного кокпита и характерного горба.

| Лист | Направление | Главное изменение формы |
|---|---|---|
| [A4 — Сварной панцирь](rh_freighter_A4_sheet.png) | Грубая броневая переделка | Крупные донорские бронеплиты, сварной нижний пояс, силовые опоры и проушины вокруг горба |
| [B4 — Сборщик трофеев](rh_freighter_B4_sheet.png) | Грузовик сборщиков лома | Два грузовых захвата, нижняя несущая рама, открытые узлы и крепления для подобранного груза |
| [C4 — Грузовик налётчиков](rh_freighter_C4_sheet.png) | Самый угрожающий силуэт | Наклонные броневые плечи, тяжёлый передний пояс, боковой грузовой затвор и усиленная корма |
| [D4 — Раздетый каркас](rh_freighter_D4_sheet.png) | Сильно переделанный утильщиками корпус | Снятая наружная обшивка, глубокие ниши, крупные трубы и диагональные опоры над герметичным внутренним корпусом |
| [E4 — Корабль из доноров](rh_freighter_E4_sheet.png) | Асимметричные ремонтные детали | Разные неподвижные бортовые кожухи, крупный сварной стык горба, восстановленные кожухи двигателей |

Для выбора направления: B4 наиболее явно передаёт работу джанкеров;
C4 сильнее выражает характер налётчиков. D4 подчёркивает происхождение со свалки.
Это художественная оценка, окончательный выбор остаётся за пользователем.

## Сохранённые ограничения

- На каждом листе перспектива, профиль и вид сверху; всё показано в полёте.
- Масштаб и соотношение корпуса к кабине ориентированы на исходный RH freighter:
  ширина 9.4647, высота 11.4625, длина 23.7217 в единицах исходной модели.
- Высокий арочный горб остаётся главным признаком верхнего силуэта.
- Исходная кабина — неизменяемый модуль. В будущей модели нужно переиспользовать
  её настоящую геометрию, остекление, материалы, UV и cockpit-ресурсы.
- Крыльев нет. В массивных бортовых выступах по три выдвижных цилиндра:
  большой в центре, два меньших по краям. Неподвижные ремонтные детали не должны
  пересекать их ход. Исходная схема использует четыре Pris-канала: большой
  цилиндр и малая пара отдельно на каждом борту.
- Два кормовых двигателя стоят слева и справа на одной высоте. В A4 отдельно
  исправлен профиль, где генерация первоначально показала лишний смещённый силуэт.
- Оружие остаётся отдельным игровым оборудованием. В корпус не встроены стволы
  и турели. Для внешней геометрии нельзя использовать семейство `metal`/`metal03`,
  зарезервированное для внутренности грузового отсека.
