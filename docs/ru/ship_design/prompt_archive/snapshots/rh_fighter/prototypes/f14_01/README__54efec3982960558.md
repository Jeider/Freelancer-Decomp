## Форма

Основа — выбранный F14, корма — большой REAR 3/4 F14_R02, с последующим
пожеланием утопить барабан на 40% диаметра. Круг неподвижный, ось вдоль Z.
Диаметр круглой наружной щеки исходника измерен отдельно от частичного фланца:
4.71165; новый диаметр такой же. Толщина нового корпуса барабана 1.40.
Крыша у барабана Y=1.55, центр Y=2.021165, нижняя точка −0.33466,
верхняя 4.37699. Под крышей ровно 40%, над крышей 60% диаметра.
Двигатели опущены вместе с кругом на 1.88466 относительно неутопленной посадки;
их центры X=±1.8140, Y=−0.051961. Новые опоры соединяют двигатели с корпусом.

Сделаны клиновидный корпус, крупные боковые углубления с тремя дополнительными
прорезями, стреловидные вперёд крылья, закрытые корневые посадки, передняя
трапециевидная ниша с пятью прорезями, две глубокие задние ниши с широкими
внутренними ступенями. Есть стенки, дно трюма и приёмный канал крышки.

Кабина извлечена из исходного Root с отсечением по Z=−4.70, уже за остеклением.
Сохранены исходные координаты, UV и стекло; на пересечённых треугольниках шеи
интерполированы вершины. Новый переход построен по реальному сечению отсечки,
без изменения кабины. Исходные 49 HP сохранены в JSON как справочные данные;
в статический CMP они ещё не перенесены. Не редактировать HP в этом прототипе
как в финальном анимированном корабле: разделение деталей пока эскизное.

## Материалы и ограничения стадии

В Blender нейтральный материал для оценки формы; родные изображения упакованы
как справочные узлы, но к цвету шейдера пока не подключены. В CMP внешние
ссылки на существующую пиратскую MAT, с предварительными UV новых деталей.
Это **не готовая покраска**. Кабина использует исходные UV. Новая отдельная MAT
не нужна, Material/Texture Library в CMP отсутствуют. `metal` снаружи не используется.

Всего 2387 треугольников, один уровень. Крылья статически раскрыты; окончательный
перенос осей/кареток, промежуточные положения крыльев, HP, damage, SUR, wire и
дальние LOD — после визуального согласования. Файлы не устанавливались в игру,
активный shiparch и Pythonlancer не менялись, игра не запускалась.

## Проверки

- Оба CMP повторно разобраны: треугольники, координаты, UV, нормали совпадают
  с исходной геометрией с погрешностью float32 не более 2.38e−7.
- Свежая соль каждого экспорта, согласованные приватные .3db/.vms и CRC;
  карта в `geometry.json`. Семантические имена и внешние материалы не засолены.
- Замкнутые новые боковины, шея, посадки, крылья, двигатели и барабан:
  нет открытых/неманифолдных рёбер, согласованный winding, положительный объём.
  Root — составная оболочка; проверка отдельных деталей не означает сваренную
  топологию всего корабля. Исходные границы стекла/кабины сохранены.
- Родная крышка: 31 положение по её настоящему смещению
  (0, 0.29331333136, 3.35259188712), без пересечений с новым корпусом.
- Проверены лицевые попадания лучей во дно и стены открытого трюма.
- Blender сохранён и повторно открыт; в рабочем виде включён back-face culling.

Подробности: [геометрия, источники, хеши, экспорты](geometry.json),
[проверка Blender](blender_check.json). Генераторы:
`tools/procedural_ships/rh_fighter_f14_form.py` и `rh_fighter_f14_blender.py`.

Повторная сборка из корня репозитория:

```powershell
python -B tools/procedural_ships/rh_fighter_f14_form.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_fighter_f14_blender.py
```

Исходные CMP/MAT и оба арта закреплены путями/SHA256 в JSON. После сборки
их хеши повторно сверены. Промпты/выбранные арты не менялись.
