# F01 body / 01 — новый центральный корпус

19 ноября 2026. Пользователь счёл корпус F14 UV/01 слишком простым и попросил
прототип на основе идей F01. Барабан, двигатели, крылья и нос предыдущей версии
ему подходят. Это ограниченная переработка корпуса, а не переход на весь F01.

## Что взято из F01

Источник: [F01, round_01](../../concepts/round_01/rh_fighter_F01_sheet.png).
Основные наблюдения — по крупной перспективе и SIDE / FLIGHT:

1. Низкая протяжённая передняя палуба переходит диагональным уступом в более
   высокий задний блок. Вместо длинного одинакового скоса появился явный излом.
2. Передняя боковая панель и небольшая задняя щека — отдельные углублённые
   поля, связанные общим силовым контуром, а не одной длинной капсулообразной нишей.
3. Между ними — косая глубокая вентиляционная ниша с четырьмя толстыми
   наклонными лопатками. Стенки, дно, толщина и наклон выполнены геометрией.
4. На поднятом заднем участке палубы — три настоящих утопленных поля,
   развивающих членение верха на F01. Заклёпки и мелкие замки не моделировались.

Это авторская адаптация идей F01 к уже принятой компоновке F14. Продольный
барабан, один двигатель, крылья и стилизованная кабина из F01 не переносились.
Нынешний поперечный барабан и два пониженных двигателя сохранены.

## Границы изменений

Основа: [F14 UV/01](../f14_uv_01/README.md), `geometry.json` закреплён хешем.
Заменены только `Port_carved_flank`, `Starboard_carved_flank` и
`Sculpted_roof_shoulders`. Остальные **16 объектов** полностью совпадают
с предыдущей моделью, включая координаты, нормали, UV и материальные назначения.
В частности: кабина/стекло/переход носа, оба крыла с корнями, двигатели с посадками,
барабан, нижняя часть корпуса с полостью трюма и подвижная крышка.

Передний стык корпуса остался на Z=-4.25. Контур снизу прежний, поэтому он
сохраняет соединение с килем и крыльями. Верх переднего участка около Y=1.0,
поднятый задний участок Y=1.86, переход к барабану возвращается к Y=1.55.
Ступени интерпретированы из перспективы, это не метрическая реконструкция арта.

UV новых трёх объектов предварительные: существующие нативные материалы
поставлены для читаемости зон в CMP. Чистовой раскладки мелких панелей, равномерной
плотности и согласования всех поворотов текстуры здесь ещё нет. Для оценки
новой формы предназначены прежде всего нейтральные ракурсы `form_*`.
В Blender материалы подключены для удобства; форма видна в Solid mode.

## Проверки

19 885 треугольников, один LOD, 19 статических объектов. Каждая новая боковина
с лопатками — 192 треугольника, новая крыша — 240. Это не назначенный лимит:
геометрия построена по крупным плоскостям, выемкам и их толщине.

- [Проверка сохранённых объектов](preservation.json), [итоговая валидация](validation.json).
- [Blender](blender_check.json): 14 замкнутых деталей проверены на рёбра,
  направление граней и положительный объём. Составная крыша и исходные оболочки
  отдельно учитываются; проверка не объявляет весь корабль одним замкнутым телом.
- Крышка прошла 31 положение без найденных пересечений. При первой проверке
  она касалась нижней плоскости кормового скоса; там уменьшена толщина крыши,
  траектория крышки не менялась. Пол и стены трюма проверены лицевыми лучами.
- Оба CMP перечитаны, свежие соли и таблицы приватных ресурсов записаны в
  [geometry.json](geometry.json). Максимум VMS: 13 115 вершин / 24 822 индекса.
- MAT остаются внешними; источники и арт закреплены SHA256. Сохранённый blend
  переоткрыт. Игровые файлы не изменялись и игра не запускалась.

Прототип ожидает визуального просмотра. Риг, повреждения, финальные HP, SUR,
wire и дальние LOD этим проходом не делались.

```powershell
python tools/procedural_ships/rh_fighter_f01_body.py
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_fighter_f14_blender.py -- --variant f01_body_01 --cull
python tools/blender_workspace.py --topic ship_design --script tools/procedural_ships/rh_fighter_f14_blender.py -- --variant f01_body_01 --cull --textured --quick
python tools/procedural_ships/rh_fighter_f01_body.py --check
```
