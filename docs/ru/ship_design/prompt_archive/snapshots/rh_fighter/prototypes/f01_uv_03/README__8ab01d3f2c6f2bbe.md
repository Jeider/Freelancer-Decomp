Финальный игровой риг, SUR, разрушения и дальние LOD остаются на следующий этап.

## Что изменено

Трюм теперь лежит непосредственно под створками: X ±0,74, Z −3,90…−1,66.
Пол поднят до Y=0,55; глубина от середины кромки — около 0,46 единицы.
Длинная полость и приёмник старого сдвижного baydoor удалены. Внутренние
стенки, пол и внутренние стороны створок используют крупные карты metal03D,
без повторов корпусной обшивки. Две створки по-прежнему открываются наружу.

Переднее боковое красное поле разделено перемычкой на два настоящих выреза.
Красные панели уменьшены; стенки вырезов тёмно-коричневые. Прежнее указание
про передний полукруг заменено этой поздней правкой. Полукруги из исходного
rh_fighter размещены в двух кормовых нишах барабана. Для них проверены реальная
панель panel02 и её карты в исходной геометрии, а не только видимый скриншот.
Круглый нижний люк кормы исправлен по пропорциям рисунка.

Вместо треугольной опоры двигатель охватывает широкий переход из корпуса.
Передние и задние секции выделены panel03 и тёмными кольцевыми стыками;
принятая центральная броня сохранена. Внутренняя чашка полностью находится
внутри наружной оболочки, устранено её пересечение с наружной обшивкой.

Крыло сохраняет прежнюю геометрию и одинаковую раскладку сверху и снизу.
UV боковины развёрнута вдоль физического края; линии текстуры параллельны
крылу, а не общей диагональной проекции.

## Новое складывание

Последнее указание пользователя отменяет подъём из UV/02. Крыло поворачивается
на 15,90755° до горизонтали, затем каретка задвигается внутрь на 1,35 единицы.
Первое движение занимает 38% цикла, затем начинается перенос. Паз в корпусе
имеет закрытые стенки и две поперечные направляющие. Нижний скос обшивки
согласован с пазом; движущийся корень не проходит через старую сплошную панель.

Примерно первая секция скрывается в корпусе, две внешние остаются снаружи.
Площадка у внешнего конца крыла сохранена для оружия. Конкретная модель пушки
и её полный габарит ещё не установлены: окончательный зазор с оборудованием
проверяется при финальной расстановке HP. Пять существующих пробных HP
перенесены без перестановки; исходные три CMP UV/02 сверены с их хешами.

проверку. Промежуточные кадры видео очищены.
