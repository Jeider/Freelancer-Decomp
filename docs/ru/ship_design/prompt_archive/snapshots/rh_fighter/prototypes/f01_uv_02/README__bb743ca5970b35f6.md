## UV и материалы

Убрана частая мелкая раскладка на крыше, торцах кормы и профилированном кольце.
Кромки кольца и плечи крыши используют panel03; бледные основные поля остаются
более спокойными. Стенки вырезов и посадочных карманов выделены тёмно-коричневым
внешним материалом. На задней перемычке — один прямоугольный и один круглый
люк из исходного panel01, каждый с полным рисунком.

На двигателях сохранён способ раскладки принятой центральной брони. Плечи и
сопловые обводы объединены непрерывной картой по длине реального профиля;
тонкие физические стыки выделены отдельно. UV не сбрасывается на каждом кольце.
Сами двигатели, их размеры и посадка не менялись.

Кабина, стекло, принятая форма бортов, крылья, дно и обе створки сохранены.
Верх и низ крыла по-прежнему имеют одинаковые карты. Новых текстур/MAT нет:
используются внешние `rh_pir_playerships.mat` и `envmapbasic.mat`.

## Смена складывания

Пользователь отклонил поворот крыла внутрь из UV/01 и выбрал принцип
rh_alt_elite. Исходный файл повторно проверен по SHA-256:
`D:/Games/FL_MOD/DATA/ships/rheinland/rh_elite/rh_alt_elite.cmp`,
`f77b661900c72dadc5bf779505108f28b7804ae2b9abdfc45b205bb8806a6c99`.

У исходника цепочка `wing_lod1 → wing1_lod1 (Pris) → wing2_lod1 (Rev)`.
Основной скрипт имеет ход Pris 1→0 и Rev 100°→0° за 2 секунды; относительная
матрица крыла уже повёрнута, поэтому это соответствует подъёму из полётной
позы. Launch заканчивается в полётной позе. Направление проигрывания проверено
по контроллеру, а не по слову extend. Родной Pris движется поперёк корабля;
перенос вперёд — именно новая адаптация по просьбе пользователя.

Здесь крыло вместе с отдельной кареткой сначала проходит 0,80 вперёд по −Z
в С-образной направляющей. Затем само крыло поворачивается вверх на 100°
вокруг продольной оси. Каретка при вращении остаётся в направляющей.
С учётом исходного наклона крыла его итоговая плоскость почти вертикальна.
Ось каждой стороны: X=±1,90, Y=−1,13. Переход от переноса к подъёму — на 38% хода.

Для контроля есть отдельные объекты направляющих и кареток. Посадочные
контакты крыла с двумя опорами каретки записываются отдельно; пересечения
с корпусом, двигателями, створками и неподвижной направляющей не допускаются.
Нормали вогнутого С-профиля определены по каждому ребру, а не от его центра.
