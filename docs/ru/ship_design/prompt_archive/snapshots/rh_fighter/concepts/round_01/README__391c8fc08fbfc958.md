# F01/F02 — первый поиск RH pirate fighter

Сначала пользователь оценил оба как слишком похожие на исходник. После отказа
от демонических D01/D02 и тяжёлых R01/R02 он вернулся к **F01/F02 как к более
удачной основе для развития**. Это не выбор одного конкретного листа.
Демоническая тема полностью отменена. Продолжение: [F03/F04 с повёрнутым
барабаном RH/A, двумя двигателями и разными опорами крыльев](../round_04/README.md).

- [F01 — Восстановленный рейнландский истребитель](rh_fighter_F01_sheet.png).
- [F02 — Клиновидный налётчик из донорских секций](rh_fighter_F02_sheet.png).
- [Фактические промпты встроенного image_gen](prompts.json).
- [Актуальная карточка корабля и механика](../../README.md).

Оба листа: три вида, полётные крылья, один кормовой двигатель и неподвижный
круглый узел. Кабина задана неизменной; будущая модель должна переиспользовать
исходный модуль, а не воспроизводить стилизованные ИИ-окна. Все материалы
генерации сохранены, файлы F01/F02 не перезаписываются.
