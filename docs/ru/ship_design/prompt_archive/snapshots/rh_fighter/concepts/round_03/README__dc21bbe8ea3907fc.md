# RH fighter — круглый барабан, вырезы и грубый ремонт

Два пробных направления R01/R02 от 17 ноября 2026. **Отклонены пользователем:**
истребитель стал слишком тяжёлым, кокпит изменён, барабан слишком большой.
Оба листа — архив; не использовать их как утверждённые пропорции.
Последнее указание: исходный кокпит и объём барабана не менять, искать форму корпуса.
Актуальная установка пользователя: рейнландский корабль на службе пиратов;
демоническую тему полностью убрать, CORSAIR пока не использовать. Форму менять
через глубокие вырезы и ремонтные секции. Круглость кормового барабана важна.

на истребитель нельзя.

## Проверка и ограничения для моделирования

Первая генерация ошибочно перенесла кабину грузовика из стилевого референса Q13
и показала стрелку baydoor вперёд. Выполнена адресная правка обоих листов:
в `v2` восстановлены характерные формы кабины истребителя (широкая нижняя полоса
лобового стекла, исходный подбородок и бровь), стрелка обращена к корме;
у R01 исправлена проекция крыла сбоку. Первые PNG без `_v2` — история ошибки,
не текущие листы для оценки.

**В модели кабину переиспользовать из исходного CMP без изменений.** Арт остаётся
иллюстрацией, не новой геометрией стекла, рамок или пилотского модуля.
На `v2` визуально проверены узнаваемость кабины, круглая масса, отсутствие
демонических деталей, направление крыльев в плане, один двигатель и стрелка люка.
Точное совпадение геометрии и всех проекций не утверждается.

Барабан неподвижен. Прямоугольная крышка в шее сдвигается назад и немного вверх;
новая форма должна оставить ей непрерывный ход и приёмный карман под задним
плечом. Арт сам по себе не подтверждает этот зазор. Два движения крыла также
сохраняются: внутренняя секция сдвигается, внешняя поворачивается вверх вокруг
продольной оси. Положение и полный ход шарниров проверять при построении модели.
Не заменять исходную цепочку Pris → Rev условным единым суставом из рисунка.
