# BW pirate — два пробных семейства B01 / B02

Пользователь запросил два пробных арта, **на каждом сразу всё семейство**:
fighter, elite и vheavy_fighter. Подготовлены два листа 1024 × 1536.
Каждый содержит три ряда: большая перспектива, профиль и вид сверху для
каждого класса. [Общая галерея](index.html).

| Лист | Направление |
|---|---|
| [B01 — Клиновидные секции](bw_family_B01_sheet.png) | Вытянутые боковые ниши носа, острые крылья, глубокий вырез в киле; более непрерывные диагональные переходы |
| [B02 — Ступенчатые плечи](bw_family_B02_sheet.png) | Выраженные посадки крыльев, ступенчатый корпус, широкие утопленные решётки, составные стыки боковых секций vheavy |

Ни один вариант пока не выбран для моделирования. Это общий поиск формы,
а не шесть отдельных несвязанных дизайнов. Сохраняются низкий fighter с одним
двигателем, двухъярусный elite с нижней гондолой и vheavy с большими просветами.

## Кабина и ограничения пробников

Первый проход изменил кабины: появились лишние стеклянные секции, тонкие
переплёты и вытянутый фонарь. Для обоих листов выполнен отдельный проход
исправления по крупным видам трёх исходных кабин. В галерее показаны именно
результаты этого исправления; первоначальные PNG оставлены для истории.

Вернулись сплошная металлическая крыша, крупное переднее стекло и низкое
клиновидное боковое окно. Однако точное совпадение контура стекла, пропорций
оболочки и всех проекций с исходным CMP не подтверждено. **Правило неизменной
кабины остаётся жёстким требованием**, а не разрешением моделировать новую
кабину по этому растру. На следующем этапе использовать исходный модуль.

У vheavy внешний обвод местами всё ещё выглядит рамным: при дальнейшей
разработке интегрировать его в корпусные/крыльевые секции и сохранять проёмы.
Посадки сдвижных крыльев, ход двух створок и ориентация нижнего двигателя
требуют согласования с [проверенной механикой](../../README.md). Тёмный торец
нижней гондолы B01 не является заданием направить сопло вперёд.
[Наблюдения по результатам](visual_review.json).

## Промпты, референсы и проверка

Использован встроенный **image_gen**, по два отдельных вызова на каждом
проходе. Начальная попытка с семью референсами была отклонена до генерации;
фактические вызовы используют по пять. Внутренние шаги/вычислительный бюджет
генератора не задавались и не заявляются.

- [Точные задания двух направлений](prompts.json): исходный результат и
  текущий результат для просмотра отмечены разными полями.
- [Точные правки кабин и порядок референсов](correction_prompts.json).
- [Неисполненная начальная попытка и причина отказа](attempt_01_prompts.json).
- [PNG, размеры, SHA-256, исходные пути и проверка CMP](artifacts.json).
- [Постоянный архив промптов](../../../../../docs/ru/ship_design/prompt_archive/README.md).

Исходные и исправленные арты сохранены раздельно. Все четыре PNG совпадают
с оригиналами генератора. Итоговые изображения декодированы; хеши трёх
исходных CMP сохранились. Новая геометрия и установка не выполнялись.
Промпты, входные референсы и результаты сохраняются при удалении этой папки.

Галерея/проверки: `python tools/procedural_ships/bw_family_art_gallery.py`.
Архив: `python tools/procedural_ships/archive_ship_prompts.py` и `--verify`.
