# BW pirate — десять вариантов семейства B03–B12

18 ноября 2026. Пользователь прекратил отдельный поиск точности кабины и заказал
десять вариантов, чтобы подумать над направлением. Требование сохранять исходную
кабину не отменено. Выбор для моделирования не сделан.

На каждом листе всё семейство: fighter, elite, vheavy; для каждого — перспектива,
профиль и вид сверху. Это десять отдельных семейных направлений, всего тридцать
корабельных концептов. Генерация выполнена встроенным `image_gen`.

## Источники

Пять изображений в каждом вызове, в фиксированном порядке:

1. Исходная текстурированная кабина в четырёх видах.
2. Та же геометрия с нейтральной оболочкой.
3. Три текущих корабля BW в полёте и проекциях, в одном масштабе.
4. B01/R2 для нечётных номеров или B02/R2 для чётных — ориентир подачи и деталей.
5. Исторический `bw_elite.png` — только характер корпуса и вертикальная компоновка.

В каждом промпте явно указано: кабинный референс важнее сгенерированного листа
и старого арта. Сохраняется вытянутое центральное стекло по наклонной поверхности
и два боковых окна; ошибочная инструкция первого прохода про сплошную крышу
не используется. [Эталон и извлечённые контуры](../../references/cockpit_lock/README.md).

## Для дальнейшего выбора и моделирования

Это поиск форм. Растровые виды не подтверждают точность исходной кабины,
согласованность проекций или работоспособность механизмов. Исходный меш кабины,
оболочка, рамки, масштаб и положение сохраняются при реализации.
Выдвижение крыльев и верхние две створки baydoor берутся из проверенного аудита.
У fighter один двигатель; у elite/vheavy по два, один верхний и один нижний.
Лишние тёмные торцы и дубли сопел на рисунке не меняют это требование.
Боковые объёмы vheavy должны оставаться цельными корпусными секциями вокруг
крупных проёмов, с разъёмами подвижных частей, без нового декоративного каркаса.

Все десять финальных листов просмотрены. PNG сохранены без изменения пикселей,
совпадение копий с результатами генератора проверено по SHA-256. Исходные CMP
не изменены. Окончательные результаты проверки файлов — в [artifacts.json](artifacts.json),
заметки по просмотренным изображениям — в [visual_review.json](visual_review.json).
Промпты, референсы и все результаты сохраняются в постоянном архиве независимо
от папки эксперимента. Выбранные RH Q13 и F14 остаются без изменений.
