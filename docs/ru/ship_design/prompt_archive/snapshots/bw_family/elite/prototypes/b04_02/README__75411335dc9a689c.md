Переделаны крупные плечи, сопряжение крыльев, план верхнего крыла, носовые
воздухозаборники, центральный киль и нижняя гондола. Кабина исходная и неизменная.
2098 треугольников. Анимацию предстоит приспособить после обсуждения формы.
