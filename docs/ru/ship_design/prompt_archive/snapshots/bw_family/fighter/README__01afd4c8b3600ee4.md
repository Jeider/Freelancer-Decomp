# bw_pir_fighter — исходник для семейства BW

**Кабина остаётся исходной целиком**, включая оболочку, стекло, рамки, размер,
положение, UV/материалы и cockpit-ресурсы. ИИ-интерпретация кабины с исторического
арта не заменяет этот модуль. [Крупные виды](cockpit_reference.jpg).

Низкий широкий силуэт, одна пара треугольных крыльев и один осевой двигатель. Длинный нос и исходная кабина задают общую продольную основу семейства.

## Механика и следствия

Две подвижные секции: при уборке идут внутрь на 2, вверх на 0.4 и назад на 0.3 единицы. Сдвиг, без вращения крыла.

`Sc_extend wing`: 1 → 0, 1.5 с; t=0 — полёт, конец — сложено.
`Sc_launch extend` заканчивается в 6.5 с в той же полётной геометрии.
Baydoor: две верхние створки за кабиной, `Root → Rev`, около ±Z,
0 → 70° за 3.3333 с. Проверены родительские связи и реальное направление
контроллера; в будущем оставить пространство над створками и стены/пол трюма.
