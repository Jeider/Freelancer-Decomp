# Кэш материалов комнаты

При создании `FRoomRuntime` клиент открывает срок жизни кэша. Загрузка групп
материалов тела, головы, аксессуаров и объектов THN вызывает предварительную
загрузку подходящих карт RP9. После синхронизации персонажей и создания сцен
клиент также обходит уже загруженные материалы: это покрывает повторное
использование тела из штатного кэша без нового чтения DFM.

Имена материала и `Dt_name` берутся из публичных методов `IMaterial`, включая
обёртку batched material. DFM повторно не читаются. Прогреваются карты одежды,
волос и подходящих объектов комнаты, а также обычный и скелетный варианты
шейдера комнаты. Вызовы D3D остаются на потоке загрузки/отрисовки.

Пока существует хотя бы одна комната, карты не удаляются по возрасту кадров.
Общие файлы используют одну текстуру с учётом COM-ссылок. При уничтожении
последней комнаты текстуры освобождаются; шейдеры остаются. Перекрытие сроков
жизни комнат при переходе безопасно. Отсутствующая карта проверяется один раз
за посещение, сохраняя штатный материал. Обычный reset устройства сохраняет
managed-текстуры; полное освобождение GPU сбрасывает отметки предварительной
загрузки.

`IRPRoomMaterialCache` — отдельный необязательный интерфейс. Старые клиенты
сохраняют прежнее ограниченное по кадрам хранение; клиент без этого интерфейса
работает по старому пути. Файловое определение типа комнаты и запись
`room_bar.txt` теперь выполняются при изменении комнаты, а не каждый кадр.

Проверка: `tools/room_materials/check.py --startup-build --objects
out/room_materials/runtime/obj/RP9`. GPU-тест проверяет предварительную загрузку
реального PNG волос, 1000 кадров вне камеры, общие карты, нескольких владельцев,
отсутствующие файлы, освобождение устройства и сохранение состояния отрисовки.
Существующие проверки света, кожи, волос, комнат и теней также выполняются.

Это устраняет повторные чтения дополнительных карт материалов внутри
посещения. Позднее появление нового объекта всё ещё может потребовать загрузки
его ресурсов при создании. Геометрия, звук и остальные причины задержек этим
кэшем не заменяются. Проверку плавности в игре выполняет пользователь.
