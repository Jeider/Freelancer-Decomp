# Realistic anomaly studies — maximum-quality source revision

27 October 2026. [Русский](../ru/space_anomalies/realistic.md).

Eight new standalone presets target convincing scale, restrained colour, strong lighting contrast and detailed structure. Elite Dangerous / Star Citizen are the user's quality references, not engines whose implementation is being reproduced.

**Eight genuine GPU captures are available at 3840×2160:** [gallery](realistic_previews/report.html) · [contact sheet](realistic_previews/overview.jpg). The user authorized compilation of the isolated preview fixture. The game was neither compiled nor modified for this preview task. The earlier gallery remains a separate theatrical study.

The three black holes now use RK4 null-geodesic integration in a Schwarzschild orbital plane, with `r_s=1`, `u''=-u+1.5u²`, and the static observer's local-frame impact parameter. The photon sphere is at `r=1.5`; the critical impact is `3√3/2`. Disk intersections create lensed images instead of painted arcs. An opaque, geometrically thin photosphere, a temperature profile with inner edge near `3 r_s`, orbital frequency shifts and three sampled Planck bands supply the disc appearance. Shifting a blackbody temperature already accounts for spectral beaming; it is not multiplied by another Doppler factor. See the [primary geodesic paper](https://doi.org/10.1088/0004-637X/800/1/77) and [NASA visualization](https://svs.gsfc.nasa.gov/14619/).

This is a numerical nonrotating model, not Kerr/GRMHD. Full spectral colour integration, light-travel-time evolution and fluid dynamics are absent. Background radiometry and advected structure remain approximations. The horizon bonus is an exterior approach, not a fictional interior labelled realistic.

Pulsars use a small hot core, tilted rotating axis, narrow structured outflows and angle-dependent intensity. Magnetars use sparse plasma loops and a directed eruption rather than a regular magnetic cage. Their `sensor=1` presets deliberately visualize otherwise invisible radiation. [NASA labels magnetic-field depictions as illustrations](https://science.nasa.gov/asset/hubble/illustration-of-magnetar/).

The quasar separates an almost unresolved nucleus from an absorbing clumpy dust torus with self-shadowing and unequal bipolar jets. RGB extinction reddens transmitted light. The microquasar has a donor star, irradiated hemisphere, curved mass-transfer stream and a resolved compact disk. Display scales are compressed for the composition. [NASA's active-galaxy overview](https://science.nasa.gov/universe/galaxies/types/) supports the physical architecture.

Default `realistic/epic` budgets: 3840×2160, FP16 HDR, up to 1024 RK4 steps per ray, four subpixel rays near the capture boundary, 512 volume samples, five noise octaves, eight dust-shadow samples, 4096×2048 background and 22,000 stars. Glare uses an exposure-aware threshold. SM3 compilation and rendering were verified on an RTX 5080 using D3D9 HAL. These are sample budgets, not measured game frame rates or a legacy-GPU compatibility guarantee. Such ray tracing can cost more GPU time than a particular ALE scene even while avoiding particle-count and CPU submission constraints. CIG's [official lighting presentation](https://robertsspaceindustries.com/en/comm-link/transmission/17586-Inside-Star-Citizen) is an art reference only.

`tools/space_anomalies/check_realism.py` runs interpreted double-precision tests for the conserved geodesic integral, analytic photon sphere/capture boundary, weak deflection and step convergence, plus static preset/include/Python syntax checks. For `b=100 r_s`, deflection is approximately 0.0202995 radians versus the leading weak-field term 0.02. Halving the step at `b=3.2 r_s` changes deflection by about 6×10⁻⁹ radians. These numbers describe the CPU reference, not measured GPU float error.

The [lab README](../../tools/space_anomalies/README.md) contains reproduction commands. `report_realistic.py` checks GPU logs, repeatability, orbit/flare changes and genuine 4K captures. The static quiet black hole is correctly exempt from mandatory temporal animation. HDR readback checks FP16 exponent bits directly, because the legacy D3DX conversion alone can disguise NaN/Inf as finite values.

Preview work exposed the SM3 temporary-register limit when evaluating the three-sheet disk inside the integrator. The final implementation uses an opaque thin disk and evaluates its radiance after integration. Numeric state with an exact zero loop condition also avoids incorrect legacy compiler lowering observed with nested boolean exits. The fixture caches expanded shaders and uses optimization level 1. Disk noise frequencies were reduced to avoid grain-like aliasing; jets and sensor response were adjusted for readability. These are art-directed prototypes, with no full fluid simulation, cinematic lens model or in-game depth integration.
